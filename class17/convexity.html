Problem classes and convexity

All non-linear problems share one general form, but they are far from equally hard. Convexity is the dividing line. This part gives the definitions and the tests for recognizing it.

The general problem

\[ (\text{NLO})\quad \min\ f(x) \quad \text{s.t.}\quad g_i(x) \le 0,\ i = 1, \dots, m, \qquad h_j(x) = 0,\ j = 1, \dots, \ell. \]

\(f, g_i, h_j : \mathbb{R}^n \to \mathbb{R}\) are continuous, usually differentiable. The set of points satisfying all constraints is the feasible region \(\mathcal{F}\).

Classes of non-linear problems

ClassFormNote
Quadratic program (QP)\(\min x^\top Qx + c^\top x\) s.t. \(Ax = b,\ x \ge 0\)Convex QP when \(Q \succeq 0\)
Quadratically constrained QP (QCQP)\(\min x^\top Q_0 x + c_0^\top x\) s.t. \(x^\top Q_i x + c_i^\top x \le r_i,\ Ax = b\)Convex when all \(Q_i \succeq 0\)
Second-order cone program (SOCP)\(\min c_0^\top x\) s.t. \(\|Q_i x + p_i\|_2 \le s_i^\top x + r_i,\ Ax = b\)The ellipsoidal robust counterpart of class 14
Semidefinite program (SDP)\(\min \langle C, X\rangle\) s.t. \(\langle A_i, X\rangle = b_i,\ X \succeq 0\)The variable is a matrix
Non-linear program (NLP)\(\min f(x)\) s.t. \(g_i(x) \le 0,\ h_j(x) = 0\)Everything else

Roughly, the list goes from more special (and easier) to more general (and harder). LP is a special case of all of them.

Local and global optima

Definitions

Ball: \(B(\bar x, \varepsilon) = \{z : \|z - \bar x\| \le \varepsilon\}\).

Local minimum: \(x^* \in \mathcal{F}\) with \(f(x^*) \le f(y)\) for all \(y \in B(x^*, \varepsilon) \cap \mathcal{F}\), for some \(\varepsilon > 0\).

Global minimum: \(x^* \in \mathcal{F}\) with \(f(x^*) \le f(y)\) for all \(y \in \mathcal{F}\).

In linear optimization every local optimum is global. In general non-linear optimization that fails, and that is the root of most of the difficulty.

Convex sets

Definition

\(S \subseteq \mathbb{R}^n\) is convex if for all \(x, y \in S\) and \(\lambda \in [0, 1]\), \(\lambda x + (1 - \lambda) y \in S\).

The segment between any two points of the set stays in the set. A disc is convex. A crescent moon is not.

Key property: the intersection of convex sets is convex. So if each constraint defines a convex set, the feasible region is convex.

Convex functions

Definition

\(f\) is convex if

\[ f(\lambda x + (1 - \lambda) y) \le \lambda f(x) + (1 - \lambda) f(y) \quad \text{for all } x, y,\ \lambda \in [0, 1]. \]

\(f\) is concave if \(-f\) is convex.

Geometrically: the chord between any two points on the graph lies on or above the graph. A function can be convex, concave, both (linear functions) or neither.

Interactive

Chords above, tangents below

Pick a function, then move the chord endpoints \(x\), \(y\) and the tangent point. For a convex function no chord ever dips below the graph, and no tangent ever rises above it.

Building convex functions

Rather than checking the definition every time, build convex functions from known ones:

RuleStatement
Nonnegative sums\(f_1, f_2\) convex, \(\alpha, \beta \ge 0\) \(\Rightarrow\) \(\alpha f_1 + \beta f_2\) convex
Affine substitution\(f\) convex \(\Rightarrow\) \(g(y) = f(Ay + b)\) convex
Pointwise maximum\(f_1, \dots, f_k\) convex \(\Rightarrow\) \(\max\{f_1, \dots, f_k\}\) convex
Composition\(h\) convex and non-decreasing, \(g\) convex \(\Rightarrow\) \(h(g(x))\) convex
NormsEvery norm \(\|x\|\) is convex

Example: \(\sum_i w_i\|x - c_i\|\) (Fermat-Weber) is a nonnegative sum of norms of affine functions, so it is convex. \(\max_i \|x - c_i\|\) (ball circumscription) is a maximum of convex functions, so it is convex too.

Recognizing convexity

Recall the gradient \(\nabla f(x)\) and Hessian \(H(x) = \nabla^2 f(x)\), which give the first- and second-order Taylor approximations

\[ f(x) \approx f(\bar x) + \nabla f(\bar x)^\top (x - \bar x) \qquad\text{and}\qquad f(x) \approx f(\bar x) + \nabla f(\bar x)^\top (x - \bar x) + \tfrac12 (x - \bar x)^\top H(\bar x)(x - \bar x). \]
Proposition

A differentiable \(f\) is convex if and only if \(f(y) \ge f(x) + \nabla f(x)^\top (y - x)\) for all \(x, y\).

The tangent plane at any point is a global underestimator. Local information (a gradient at one point) gives global information (a lower bound everywhere). This is exactly why a zero gradient means a global minimum for convex functions.

(\(\Rightarrow\)) By convexity, \(f(x + \lambda(y - x)) \le f(x) + \lambda(f(y) - f(x))\). Rearrange to \(\big(f(x + \lambda(y - x)) - f(x)\big)/\lambda \le f(y) - f(x)\), and let \(\lambda \to 0\): \(\nabla f(x)^\top (y - x) \le f(y) - f(x)\).

(\(\Leftarrow\)) Let \(z = \lambda x + (1 - \lambda)y\). Apply the inequality at \(z\) twice: \(f(x) \ge f(z) + \nabla f(z)^\top (x - z)\) and \(f(y) \ge f(z) + \nabla f(z)^\top (y - z)\). Multiply by \(\lambda\) and \(1 - \lambda\) and add. The gradient terms cancel, leaving \(\lambda f(x) + (1 - \lambda) f(y) \ge f(z)\).

Proposition

A twice continuously differentiable \(f\) is convex if and only if \(H(x) \succeq 0\) for all \(x\).

Upward curvature everywhere. For a quadratic \(f(x) = \tfrac12 x^\top P x + q^\top x + r\), the gradient is \(Px + q\) and the Hessian is \(P\), so \(f\) is convex if and only if \(P \succeq 0\).

Recall: \(A \succeq 0\) means \(u^\top A u \ge 0\) for all \(u\), equivalently all eigenvalues are nonnegative.

Summary

  • NLO: \(\min f(x)\) s.t. \(g_i(x) \le 0\), \(h_j(x) = 0\). Classes: QP, QCQP, SOCP, SDP, NLP.
  • Convex set: contains every segment. Intersections of convex sets are convex.
  • Convex function: chords above the graph. Equivalently tangents below it, or (twice differentiable) \(H \succeq 0\) everywhere.
  • Build convex functions from sums, affine substitutions, maxima, monotone compositions and norms.
Check yourself
Quick check
Which function is convex on \(\mathbb{R}^2\)?
A norm and a linear function are both convex, and a maximum of convex functions is convex. \(x_1x_2\) has Hessian \(\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}\), which is indefinite. \(-\|x\|_2\) is concave.
