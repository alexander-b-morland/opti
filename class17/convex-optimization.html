Convex optimization

A convex problem behaves like a linear one in the way that matters most: any local minimum is a global minimum. That single fact is why convex problems can be solved efficiently and non-convex ones generally cannot.

What makes a problem convex

Convex optimization problem

With \(f, g_1, \dots, g_m\) convex:

\[ \min\ f(x) \quad \text{s.t.}\quad g_i(x) \le 0,\ i = 1, \dots, m, \qquad Ax = b. \]

Three ingredients:

  • a convex objective, minimized (or a concave objective, maximized),
  • convex inequality constraints in the form \(g_i(x) \le 0\),
  • linear equality constraints.

Each \(\{x : g_i(x) \le 0\}\) is a convex set (a sublevel set of a convex function), and \(\{x : Ax = b\}\) is convex. Their intersection, the feasible region \(\mathcal{F}\), is therefore convex.

Watch the direction and the equalities

\(g(x) \ge 0\) with \(g\) convex is generally not convex (the outside of a disc). A non-linear equality \(h(x) = 0\) is generally not convex either (a circle is not a convex set). That is why only linear equalities are allowed.

Which models are convex?

ModelConvex?Why
Linear optimizationYesLinear functions are convex. Polyhedra are convex sets.
Fermat-Weber: \(\min \sum_i w_i\|x - c_i\|\), \(Ax \le b\)YesNonnegative sum of norms
Ball circumscription: \(\min \rho\) s.t. \(\|x - c_i\| \le \rho\)YesEach constraint \(\|x - c_i\| - \rho \le 0\) is convex
QCQP with \(A_i^\top A_i\) form: \((A_ix + b_i)^\top(A_ix + b_i) - c_i^\top x - d_i \le 0\)YesA squared norm of an affine function plus a linear term
Portfolio: \(\min x^\top \Sigma x\) with linear constraintsYesA covariance matrix is positive semidefinite
Floor planning with \(w_i h_i \ge A_i\)Not as writtenThe constraint function \(A_i - w_ih_i\) is not convex. The set it describes (with \(w_i, h_i > 0\)) is convex though, and writing it as \(h_i \ge A_i/w_i\) puts it in convex form. The aspect ratio bounds are linear: \(l_iw_i \le h_i \le u_iw_i\).
Why a covariance matrix is positive semidefinite

For any vector \(u\), \(u^\top \Sigma u = \mathrm{Var}\big(\sum_j u_j r_j\big) \ge 0\). A variance can never be negative.

Local is global

Theorem

Let \(\mathcal{F}\) be a convex set and \(f : \mathcal{F} \to \mathbb{R}\) a convex function. If \(x^*\) is a local minimum of \(\min_{x \in \mathcal{F}} f(x)\), then \(x^*\) is a global minimum.

Suppose not: some \(y \in \mathcal{F}\) has \(f(y) < f(x^*)\). For \(\lambda \in (0, 1)\), convexity of \(f\) gives

\[ f(\lambda x^* + (1 - \lambda) y) \le \lambda f(x^*) + (1 - \lambda) f(y) < f(x^*). \]

Because \(\mathcal{F}\) is convex, every point \(\lambda x^* + (1 - \lambda)y\) is feasible. As \(\lambda \to 1\) these points get arbitrarily close to \(x^*\). So every ball around \(x^*\) contains a feasible point with a strictly smaller value, and \(x^*\) is not a local minimum. Contradiction.

Walk from \(x^*\) towards the better point \(y\) in a straight line. Convexity of the set keeps you feasible. Convexity of the function keeps the values below the straight line between \(f(x^*)\) and \(f(y)\), which slopes downward right from the start. So \(x^*\) could not have been at the bottom of its neighbourhood.

Algorithms only see locally. Gradient descent (class 18) and its relatives can certify a local minimum, never directly a global one. For convex problems that is enough. For non-convex problems a local method can get stuck, and finding the global minimum is very hard in general.

Easier and harder

  • Convex problems can be solved efficiently, because local optima are global.
  • Some convex problems are easier than others. LP is easier than SOCP, which is easier than SDP. Structure still matters for which solver and algorithm to use.
  • Non-convex problems are much harder. Integer programs (classes 10 to 12) are non-convex, which is why they needed branch-and-cut.

Summary

  • Convex problem: convex objective, convex \(\le\) constraints, linear equalities. Its feasible region is convex.
  • LP, Fermat-Weber, ball circumscription, convex QCQP and portfolio optimization are all convex.
  • For convex problems, every local minimum is a global minimum.
How this shows up on the exam

"Is this a convex optimization problem? Justify briefly." Check the three ingredients one by one, and name the rule that makes each function convex (norm, sum, max, PSD quadratic). Last year's portfolio projection problem, \(\min \tfrac12\|x - a\|_2^2\) s.t. \(\sum_i x_i = 1,\ x \ge 0\), is convex: a convex quadratic over a polyhedron.
