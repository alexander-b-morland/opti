Class 17 · Non-linear optimization

Non-linear modeling

Most real relationships are curved: risk, distance, error, area. This class shows how to write them as optimization problems, and how to tell the tractable ones (convex) from the hard ones.

Overview

The big picture

Classes 1 to 16 lived mostly in the linear world. Class 17 opens the last module of the course: non-linear optimization. Before any algorithm, two questions: how do non-linear models look, and which of them can we hope to solve?

Imagine searching for the lowest point of a landscape in the dark. In a single smooth bowl, walking downhill always gets you to the bottom. In a mountain range full of valleys, walking downhill gets you to the bottom of whichever valley you started in. Convex problems are the bowl. Non-convex problems are the range.

\[ \min\ f(x) \quad \text{s.t.}\quad g_i(x) \le 0,\quad Ax = b, \qquad f, g_i \text{ convex} \ \Longrightarrow\ \text{local optimum} = \text{global optimum}. \]

Machine learning, finance, engineering design and logistics all run on non-linear models. Recognizing convexity tells you whether a solver's answer can be trusted as the best possible, or only as a good local one. Classes 18 to 20 then build the algorithms.

Takeaways from the lecture
  1. Convex and non-linear optimization are powerful modeling frameworks.
  2. Non-linear optimization covers a vast range of problem classes, with consequences for modeling and algorithms.
  3. Convex problems can be solved efficiently, because local optima are global.
  4. Some convex problems are easier than others. Non-convex problems are much harder.

Exam practice

Test yourself

Multiple choice in the style of the midterm. Say your one-line justification before you click.

Question 1 · Convexity
Is \(\min \tfrac12\|x - a\|_2^2\) s.t. \(\sum_i x_i = 1,\ x \ge 0\) a convex optimization problem?
The Hessian of the objective is \(I \succ 0\), so it is convex. The constraints are linear. The data \(a\) does not matter.
Question 2 · Recognizing convexity
Which function is not convex?
\(x_1^2 - x_2^2\) has Hessian \(\mathrm{diag}(2, -2)\), which is indefinite: a saddle. The first is a max of norms. The second is a convex non-decreasing function of an affine function.
Question 3 · Feasible regions
\(g\) is convex. Which constraint can make the feasible region non-convex?
Sublevel sets \(\{g \le 5\}\) of a convex function are convex. Superlevel sets are not in general: \(\|x\|_2 \ge 5\) is the outside of a disc.
Question 4 · Global optimality
An algorithm returns a local minimum of a convex function over a convex set. What can you conclude?
Local equals global for convex problems. Uniqueness would need strict convexity.
Question 5 · Portfolio
Why is the portfolio variance \(x^\top \Sigma x\) a convex function?
Covariances can be negative. What matters is \(\Sigma \succeq 0\), which holds for every covariance matrix.
Question 6 · Modeling
You place an ambulance base so that no neighbourhood is too far away. Which model fits?
"No neighbourhood too far" is a worst-case requirement, so minimize the largest distance. Fermat-Weber would sacrifice remote areas for a good average.
