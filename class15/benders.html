Benders decomposition

Split the problem in two. A master problem chooses the first-stage decision with a rough picture of the future. Subproblems, one per scenario, report the true future cost and how it changes, as a linear cut.

The recourse function

Fix the first-stage decision \(x\). What remains is a separate linear program for each scenario:

\[ Q_s(x) = \min_{y_s \ge 0} \{ f_s^\top y_s : V y_s = w_s - U_s x \}, \qquad Q(x) = \sum_{s} \pi_s Q_s(x). \]

\(Q(x)\) is the recourse function: the expected cost of the future, given today's decision. The whole problem becomes

\[ \min_x\ c^\top x + Q(x) \quad \text{s.t.}\quad Ax = b,\ \ x \in \mathbb{Z}_+^r \times \mathbb{R}_+^{n_1 - r}. \]

This is the trade-off between present and future cost. A conservative strategy invests little today and pays more later. An aggressive one invests more today and benefits later. The challenge: \(Q\) is not known as a formula. We can only evaluate it at a given \(x\), by solving the subproblems.

Looking at the future through duality

Take one scenario and drop the index \(s\). By LP duality,

\[ Q(x) = \max_p\ \{ (w - Ux)^\top p : V^\top p \le f \}. \]

The key observation: the dual feasible region \(\{p : V^\top p \le f\}\) does not depend on \(x\). Only the objective does. A linear program attains its optimum at an extreme point, so if \(q^v,\ v \in \mathcal{V}\) are the extreme points of that polyhedron,

\[ Q(x) = \max_{v \in \mathcal{V}} (w - Ux)^\top q^v \qquad\text{so}\qquad Q(x) \ge (w - Ux)^\top q^v \ \text{ for every } v. \]

\(Q\) is the maximum of finitely many linear functions of \(x\): convex and piecewise linear. Each extreme point gives one linear piece, called a Benders cut.

Assumptions

The first- and second-stage feasible regions are bounded. And the problem has relatively complete recourse: for every first-stage \(x\) with \(Ax = b\), the second-stage problem has a feasible \(y\). (In facility location, unmet demand \(z\) guarantees this.)

The Benders reformulation

Replace \(Q(x)\) by a variable \(\theta\) that must lie above every cut:

Theorem

Under the assumptions, the problem is equivalent to

\[ \begin{aligned} \min_{x,\, \theta}\ & c^\top x + \theta \\ \text{s.t. } & Ax = b \\ & \theta \ge (w - Ux)^\top q^v, && v \in \mathcal{V} \\ & x \in \mathbb{Z}_+^r \times \mathbb{R}_+^{n_1 - r}. \end{aligned} \]

Far fewer variables (no \(y\) at all), but one constraint per extreme point: exponentially many. So, just like in class 14, we generate constraints only when needed. Benders decomposition is a cutting planes (row generation) method.

The algorithm

Algorithm · Benders decomposition
  1. Initialize \(t = 1\) and an empty set of cuts \(\mathcal{V}^{(1)} = \emptyset\).
  2. Master problem: solve \(\min c^\top x + \theta\) with \(Ax = b\) and only the cuts in \(\mathcal{V}^{(t)}\).
    1. If infeasible, stop: the full problem is infeasible.
    2. Otherwise get \((x_t, \theta_t)\). Lower bound \(LB = c^\top x_t + \theta_t\).
  3. Subproblem: solve the second stage at \(x_t\). Get the primal \(y_t\) and the dual \(p_t = q^{v_t}\). Upper bound \(UB = c^\top x_t + f^\top y_t\).
  4. Optimality check: if \(f^\top y_t = \theta_t\), stop: \((x_t, y_t)\) is optimal. Otherwise add the cut \(\theta \ge (w - Ux)^\top q^{v_t}\), set \(t \leftarrow t + 1\) and go to step 2.

The master only knows some of the cuts, so its \(\theta\) underestimates the true future cost. It is a relaxation of a minimization problem, and its value can only go up as cuts are added.

\((x_t, y_t)\) is an actual feasible plan, and \(c^\top x_t + f^\top y_t\) is its true cost. Any feasible plan's cost is at least the optimum.

When \(\theta_t = Q(x_t)\), the master's picture of the future is exact at its own solution, so the bounds meet. There are finitely many extreme points and each new cut is different, so the algorithm terminates in a finite number of iterations with an optimal solution.

Benders on the one-facility example

The gold curve is the true recourse \(Q(x)\) from part a (shortage cost 4). Each cut is a line touching \(Q\) at the master's current \(x\). The master trusts the dashed approximation, the maximum of the cuts.

The first master ignores the future entirely and builds nothing. Each cut teaches it the slope of the future cost at its last guess. After a few iterations the approximation is exact where it matters, at the optimum, even though it is still rough elsewhere.

One subproblem per scenario

With many scenarios, the second stage splits into \(S\) independent subproblems, which can be solved in parallel. The master gets one cut per scenario, weighted by its probability:

\[ \theta \ge \sum_{s \in \mathcal{S}} \pi_s (w_s - U_s x)^\top q_s^{v_s}. \]

In facility location

The subproblem for scenario \(s\) fixes the built facilities \(x\) and solves the transport problem. Its dual has a variable \(\lambda_{js} \ge 0\) for each capacity constraint and \(\mu_{is} \ge 0\) for each demand constraint:

\[ \max_{\lambda, \mu \ge 0}\ -\sum_j C_j x_j \lambda_{js} + \sum_i d_{is}\mu_{is} \quad \text{s.t.}\quad -\lambda_{js} + \mu_{is} \le t_{ij}\ \ \forall i, j, \qquad \mu_{is} \le u_i\ \ \forall i. \]

The dual constraints do not contain \(x\), as promised. The cut tells the master: each unit of capacity at facility \(j\) is worth \(\lambda_{js}\) in scenario \(s\).

With few scenarios both methods work. As \(S\) grows, the direct approach hits the time limit with a gap between its solution and its lower bound, while Benders proves optimality in a fraction of the time.

Summary

  • The recourse function \(Q(x)\) is convex and piecewise linear, the maximum of linear pieces from the dual extreme points.
  • Benders replaces \(Q\) by \(\theta\) and adds cuts on demand: a master problem for the first stage, subproblems for the second.
  • Master value: lower bound. Plan cost: upper bound. Stop when they meet. Exact and finite.
  • Subproblems decompose by scenario and can run in parallel.
Check yourself
Quick check
Why does a Benders cut stay valid for every \(x\), not just the \(x_t\) where it was generated?
The dual feasible set \(\{p : V^\top p \le f\}\) does not depend on \(x\). Any dual feasible point gives a lower bound on the dual maximum, which equals \(Q(x)\).
