The value of adapting

Is the two-stage model worth the effort? Compare it with a plan built for the average future, and with an ideal plan that knows the future. Two numbers summarize the gaps.

Three ways to plan

DeterministicPlan for the average scenario. Then live with the consequences in every real scenario.
AdaptivePlan the first stage knowing the future is uncertain, with a recourse for each scenario.
Wait and seePlan everything after seeing the scenario. Impossible in practice, a benchmark only.

The three formulations

\[ \min\ c^\top x + \mathbb{E}(f_s)^\top y \quad\text{s.t.}\quad Ax = b,\ \ \mathbb{E}(U_s)x + Vy = \mathbb{E}(w_s). \]

Optimize the first stage with a point forecast. Then fix that \(x\) and re-evaluate the second stage in each scenario to get its true expected cost.

\[ \min\ c^\top x + \mathbb{E}(f_s^\top y_s) \quad\text{s.t.}\quad Ax = b,\ \ U_s x + V y_s = w_s\ \ \forall s. \]

Jointly optimize the first stage and the recourse in every scenario, minimizing expected cost.

\[ \mathbb{E}\Big( \min\ c^\top x_s + f_s^\top y_s \ \ \text{s.t.}\ \ Ax_s = b,\ \ U_s x_s + V y_s = w_s \Big). \]

Solve each scenario on its own, with its own first-stage decision \(x_s\), and average. This drops non-anticipativity: it is what you could do with a crystal ball.

Each formulation gives the first stage more information than the one before, so in expected cost

\[ \text{Wait and see} \ \le\ \text{Adaptive} \ \le\ \text{Deterministic}. \]

VSS and EVPI

Value of the stochastic solution
\[ \text{VSS} = \text{Deterministic} - \text{Adaptive} \ \ge 0 \]

The value of flexibility: what you gain by planning for the spread of outcomes instead of the average.

Expected value of perfect information
\[ \text{EVPI} = \text{Adaptive} - \text{Wait and see} \ \ge 0 \]

The cost of commitment: what you lose because today's decisions cannot wait for information. An upper bound on what better forecasts are worth.

The facility location case

SolutionConstructionTransportShortagesTotal
Deterministic$547M$127M$853M$1,528M
Adaptive$842M$119M$122M$1,083M
Wait and see$574M$135M$13M$722M
  • VSS: the adaptive plan cuts expected cost by about $444M, or 29%. It spends much more on construction ($842M against $547M) and in exchange almost eliminates shortages.
  • EVPI: perfect information would save another $361M, or 33% of the adaptive cost.
  • Gap closed: the adaptive plan bridges about 55% of the gap between the deterministic plan and the wait-and-see ideal.

Notice where the deterministic plan fails. It builds for average demand, so in high-demand scenarios it runs short, and shortages are expensive. The wait-and-see plan can tailor its facilities to each scenario, which is exactly the flexibility the first stage does not have.

VSS and EVPI in the one-facility example

Change the shortage cost and watch the two measures. When does planning for the average lose nothing? When is perfect information worth a lot?

With a low shortage cost, the two-stage plan equals the average plan and VSS is zero: flexibility is worth nothing when being short is cheap. With a high shortage cost, the adaptive plan covers the high scenario and VSS grows. EVPI stays large throughout, because no single capacity fits demands as different as 40 and 160.

Summary

  • Wait and see \(\le\) adaptive \(\le\) deterministic, in expected cost.
  • VSS = deterministic minus adaptive: the value of flexibility.
  • EVPI = adaptive minus wait and see: the cost of committing early.
How this shows up on the exam

Expect sketch-and-explain questions. The practice exam asked for the optimal expected response distance as a function of the number of patrol vehicles \(K\): for very small \(K\) the problem is infeasible, since there are not enough vehicles to respond to every incident. For very large \(K\) it drops to 0, since every neighborhood can hold enough vehicles for every scenario. In between it decreases in \(K\). Combined with the cost of each vehicle, the curve tells you how many to deploy.

Check yourself
Quick check
Deterministic plan: expected cost 500. Adaptive plan: 420. Wait and see: 380. What are VSS and EVPI?
VSS = 500 − 420 = 80. EVPI = 420 − 380 = 40.
