Why stochastic gradients

Training a neural network is an optimization problem with millions of terms in the objective. Computing the exact gradient at every step is too slow. This part shows where that cost comes from and what we want instead.

A neural network as a function

A multi-layer neural network builds a non-linear function \(y = g(x)\) by stacking simple layers. Each node takes a weighted sum of the previous layer, adds a bias, and applies an activation function \(h\):

\[ z^1_k = h^1_k\Big( \sum_j w_{jk} x_j + b_k \Big), \qquad z^2_\ell = h^2_\ell\Big( \sum_k w_{k\ell} z^1_k + b_\ell \Big), \qquad y_m = h^3_m\Big( \sum_\ell w_{\ell m} z^2_\ell + b_m \Big). \]

The weights \(w\) and biases \(b\), collected in \(W\), are the decision variables. A common activation is the ReLU, \(h(z) = \max(z, 0)\).

Training is optimization

Given training data \((x_i, y_i)\), \(i = 1, \dots, n\), choose the weights that make the predictions \(g(x_i, W)\) close to the targets, as measured by a loss \(L\):

\[ \min_W\ f(W) = \frac1n \sum_{i=1}^n L\big(g(x_i, W),\ y_i\big). \]

Two features matter for the algorithm:

  • The objective is a sum over data points, one term per training example. This is the structure SGD exploits.
  • It is non-convex, because \(g\) composes non-linear activations. Class 18 warned what that means: gradient descent finds stationary points, not necessarily global minima.

Forward and backward propagation

Gradient descent iterates \(W^{k+1} = W^k - \alpha_k \nabla f(W^k)\). For a network with layers \(z_1 = h_1(x, w^{(1)})\), \(z_2 = h_2(z_1, w^{(2)})\), \(y = h_3(z_2, w^{(3)})\), each iteration needs two passes:

Forward propagation

Feed the input through the layers in order to evaluate the prediction and the loss \(f(W^k)\).

Backward propagation

Apply the chain rule from the output back to the input to get \(\partial f/\partial w^{(3)}\), then \(\partial f/\partial w^{(2)}\), then \(\partial f/\partial w^{(1)}\). This gives \(\nabla f(W^k)\).

Part b works through both passes by hand for a small network from the lecture.

The cost of one gradient

The full gradient is an average over all data points:

\[ \nabla f(x) = \frac1n \sum_{i=1}^n \nabla f_i(x). \]

For a neural network with \(m\) nodes, one gradient costs about \(O(nm^2)\) operations. With 10 million data points and 1,000 nodes, that is around \(10^{13}\) operations per iteration, and training needs many iterations.

The idea

Replace the full gradient by the gradient of a single, randomly chosen term: \(\nabla f(x) \approx \nabla f_{i_k}(x)\). That costs \(O(m^2)\), around \(10^6\) operations in the same example, ten million times cheaper. The price is that the direction is only right on average.

Two challenges, one idea

Challenge with gradient descentHow SGD responds
No guarantee of global convergence in non-convex problemsThe randomness helps escape shallow local minima and saddle points. Still no guarantee of a global minimum.
Each gradient is expensive (backpropagation over all data)Each iteration uses one data point, so iterations are much faster.

The trade-off: SGD has weaker theoretical guarantees than gradient descent, but excellent practical performance on very large, non-convex machine learning problems. It also needs experimentation and tuning to work reliably.

Summary

  • Training a model means minimizing an average loss over the data, \(f(x) = \frac1n\sum_i f_i(x)\).
  • Each gradient needs a forward and a backward pass over all \(n\) data points, which is expensive.
  • SGD uses one random term per iteration: much cheaper, noisier, and helpful against poor local solutions.
Check yourself
Quick check
What property of the objective makes stochastic gradient descent possible?
The finite-sum structure \(f = \frac1n \sum_i f_i\) means that the gradient of one random term is an unbiased estimate of the full gradient. Convexity is not required: SGD is used mostly on non-convex problems.
