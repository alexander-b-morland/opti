The SGD algorithm

Same loop as gradient descent, with one change: each step follows the gradient of a single randomly chosen data point. On average that is the right direction. Any single step can be wrong.

The algorithm

The objective is a sum, or an expectation, of component functions:

\[ \min_x\ f(x) = \frac1n \sum_{i=1}^n f_i(x). \]
Algorithm · stochastic gradient descent
  1. Choose a starting point \(x_0\). Set \(k = 0\).
  2. Repeat until a stopping criterion holds:
    1. Choose an index \(i_k \in \{1, \dots, n\}\).
    2. Take the direction \(d_k = -\nabla f_{i_k}(x_k)\).
    3. Choose a step size \(\alpha_k > 0\), often called the learning rate.
    4. Update \(x_{k+1} = x_k + \alpha_k d_k\).
    5. Set \(k \leftarrow k + 1\).

Compare with class 18: the only change is step 2.2, where \(\nabla f(x_k)\) is replaced by \(\nabla f_{i_k}(x_k)\).

Choosing the index

Draw \(i_k\) uniformly at random from \(\{1, \dots, n\}\). Then the stochastic gradient is an unbiased estimate of the true gradient, conditional on \(x\):

\[ \mathbb{E}\big[\nabla f_{i_k}(x)\big] = \sum_{i=1}^n \nabla f_i(x)\, \mathbb{P}(i_k = i) = \frac1n \sum_{i=1}^n \nabla f_i(x) = \nabla f(x). \]

Right on average, wrong in any single draw.

Go through the data in order: \(i_k = 1, 2, \dots, n, 1, 2, \dots, n, \dots\). One full pass over the data is called an epoch. Simple, but not random, so the unbiasedness argument does not apply.

Not a descent method

In class 18, \(d_k = -\nabla f(x_k)\) always satisfied \(\nabla f(x_k)^\top d_k < 0\), so small steps always decreased \(f\). With SGD it can happen that

\[ \nabla f(x_k)^\top \nabla f_{i_k}(x_k) < 0, \]

so \(d_k = -\nabla f_{i_k}(x_k)\) points uphill for the full objective. The algorithm need not make progress at every iteration, however small the step.

How this shows up on the exam

Last year's midterm: "Stochastic gradient descent with constant step size is a descent algorithm. True or false?" False: errors in the gradient estimate can make \(f\) increase at an iteration. Gradient descent with a small enough step is a descent algorithm, Newton's method with step 1 is not necessarily.

SGD for linear regression

With \(f_i(\beta) = \tfrac12\big(y_i - \sum_j x_{ij}\beta_j\big)^2\), the gradient of one term is

\[ \frac{\partial f_{i_k}}{\partial \beta_j} = -x_{i_k j}\big(y_{i_k} - x_{i_k}^\top \beta\big) \quad\Longrightarrow\quad \beta_j^{k+1} = \beta_j^k + \eta\, x_{i_k j}\big(y_{i_k} - x_{i_k}^\top \beta^k\big). \]

Each step adjusts the weights using one data point. If the prediction is too low (\(x_{i_k}^\top\beta < y_{i_k}\)) and \(x_{i_k j} > 0\), \(\beta_j\) goes up to raise the prediction. If \(x_{i_k j} < 0\), it goes down, which also raises the prediction. The opposite holds when the prediction is too high.

The first few steps are all lucky: the line sits above every point, so every point pulls it down. Soon the points start to disagree, and lucky and unlucky steps alternate. A single step improves the fit for its own point, not necessarily on average. Only the expected step points downhill. Part c turns this noise into a bound.

SGD on a neural network

The lecture's example: two inputs, one hidden layer with two ReLU nodes, one output, loss \(\tfrac12(y - \hat y_5)^2\), and a single data point \(x = (0.5, 0.8)\), \(y = 1\).

\[ \begin{aligned} h_3 &= \max(w_{13}x_1 + w_{23}x_2 + b_3,\ 0) = 0.52 \\ h_4 &= \max(w_{14}x_1 + w_{24}x_2 + b_4,\ 0) = 0.43 \\ \hat y_5 &= \max(w_{35}h_3 + w_{45}h_4 + b_5,\ 0) = 0.646 \end{aligned} \qquad L = \tfrac12(1 - 0.646)^2 = 0.063. \]

Differentiate the loss directly (the output ReLU is active, so it passes the derivative through):

\[ \frac{\partial L}{\partial w_{35}} = -h_3(y - \hat y_5) = -0.184, \qquad \frac{\partial L}{\partial w_{45}} = -h_4(y - \hat y_5) = -0.152, \qquad \frac{\partial L}{\partial b_5} = -(y - \hat y_5) = -0.354. \]

The network undershoots (0.646 against 1). Since \(h_3, h_4 > 0\), raising these weights raises \(\hat y_5\). All three derivatives are negative, so SGD will increase them.

One layer back, chain the derivatives through \(\hat y_5\) and \(h_3\):

\[ \frac{\partial L}{\partial w_{13}} = \frac{\partial L}{\partial \hat y_5}\, \frac{\partial \hat y_5}{\partial h_3}\, \frac{\partial h_3}{\partial w_{13}} = -(y - \hat y_5)\, w_{35}\, x_1 = -0.089. \]

The same logic gives \(\partial L/\partial w_{23} = -0.142\), \(\partial L/\partial b_3 = -0.177\), \(\partial L/\partial w_{14} = -0.035\), \(\partial L/\partial w_{24} = -0.057\), \(\partial L/\partial b_4 = -0.071\).

With learning rate \(\eta = 0.1\): \(w_{ij} \leftarrow w_{ij} - \eta\, \partial L/\partial w_{ij}\) and \(b_i \leftarrow b_i - \eta\, \partial L/\partial b_i\). For example \(w_{35}\) goes from 0.5 to 0.5184 and \(b_5\) from 0.3 to 0.3354. Then repeat with the next data point.

Summary

  • SGD: \(x_{k+1} = x_k - \alpha_k \nabla f_{i_k}(x_k)\), with \(i_k\) random (or cyclic).
  • With uniform sampling the stochastic gradient is unbiased: \(\mathbb{E}[\nabla f_{i_k}(x)] = \nabla f(x)\).
  • A single step can increase \(f\). SGD is not a descent method.
  • In a neural network, one SGD step is a forward pass, a backward pass (chain rule) and an update, all for one data point.
Check yourself
Quick check
In the regression update, a data point has \(x_{i_k j} < 0\) and the prediction is too high. What happens to \(\beta_j\)?
The residual \(y - x^\top\beta\) is negative and \(x_{i_k j} < 0\), so their product is positive and \(\beta_j\) goes up. Since the feature is negative, a larger \(\beta_j\) lowers the prediction, as it should.
