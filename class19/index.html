Class 19 · Non-linear optimization

Stochastic gradient descent

When the objective is an average over millions of data points, follow the gradient of one random point instead. Each step is cheap and noisy. Done right, it is how every large machine learning model is trained.

Overview

The big picture

Class 18 built gradient descent. It works, but each step needs the gradient over all the data. Class 19 trades exactness for speed: estimate the gradient from one data point, or a small batch, and take many more, cheaper steps.

\[ \min_x\ f(x) = \frac1n \sum_{i=1}^n f_i(x), \qquad x_{k+1} = x_k - \alpha_k \nabla f_{i_k}(x_k). \]

To find out which way public opinion is moving, you could poll the whole country before every decision. Or you could ask one random person each day and adjust a little each time. Any single answer may point the wrong way, but on average the answers point the right way, and you get to make far more adjustments.

Gradient descent: few, expensive, reliable steps. SGD: many cheap, noisy steps. With a constant step SGD rushes towards the optimum and then hovers in a "noise ball" around it. Smaller or shrinking steps make the ball smaller. Mini-batches sit in between.

Neural networks have millions of parameters and are trained on millions of examples. A single full gradient can cost \(10^{13}\) operations. SGD and its mini-batch versions are what make deep learning feasible, and their randomness helps avoid poor local minima in these non-convex problems.

The story of the class in four steps

19a · MotivationNeural networks: finite sums, backprop, expensive gradients.
19b · AlgorithmOne random gradient per step. Unbiased, not descent.
19c · ConvergenceLinear phase plus a noise floor. Shrink the step.
19d · PracticeMini-batches, step schedules, starts and stopping.
Four takeaways from the lecture
  1. SGD introduces randomness to speed up gradient computations and avoid poor solutions, for finite-sum objectives.
  2. Its guarantees are weaker than for gradient descent: slower convergence, an irreducible error, or both.
  3. Mini-batches are a middle ground between gradient descent (fewer, longer iterations) and SGD (more, faster, more variable iterations).
  4. SGD performs very well in practice on large-scale machine learning, especially deep learning.

For your note sheet

Update\(x_{k+1} = x_k - \alpha_k \nabla f_{i_k}(x_k)\), \(i_k\) uniform.
Unbiased: \(\mathbb{E}[\nabla f_{i_k}(x)] = \nabla f(x)\).
Not a descent method.
Strongly convex, constant \(\alpha \le 1/M\)\(\mathbb{E}f(x_k) - z^* \le (1 - \alpha m)^k(f(x_0) - z^*) + \dfrac{\alpha M\sigma^2}{2m}\)
Smooth, constant \(\alpha\)\(\min_\ell \mathbb{E}\|\nabla f(x_\ell)\|^2 \le \dfrac{f(x_0) - z^*}{k\alpha} + \dfrac{MG^2\alpha}{2}\)
\(O(1/k) + O(\alpha)\). Diminishing \(\alpha_k\) removes the floor.
Mini-batch\(d_k = -\frac1B\sum_{i \in I_k}\nabla f_i(x_k)\).
\(B = 1\): SGD. \(B = n\): GD. Cost per iteration \(\propto B\).

Exam practice

Test yourself

Multiple choice in the style of the midterm. Say your one-line justification before you click.

Question 1 · Descent
Stochastic gradient descent with a constant step size is a descent algorithm, meaning \(f(x_{k+1}) < f(x_k)\) at every iteration. True or false?
The stochastic gradient can point uphill for the full objective, \(\nabla f(x_k)^\top \nabla f_{i_k}(x_k) < 0\), so an iteration can make \(f\) worse.
Question 2 · Mini-batches
On \(\min \frac1n \sum_i f_i(x)\) with non-convex \(f_i\), mini-batch SGD and plain SGD (B = 1) are run from the same start. Which is true?
Mini-batches reduce the variance, so the method behaves more like gradient descent and can get stuck in a local minimum that plain SGD, with its higher variance, escapes.
Question 3 · Ranking
For least-squares regression on a large dataset, rank the cost of one iteration from cheapest to most expensive.
SGD uses one data point. Gradient descent uses all of them. Newton's method also needs the Hessian and a linear system solve.
Question 4 · Unbiasedness
Under which index rule is \(\mathbb{E}[\nabla f_{i_k}(x)] = \nabla f(x)\) guaranteed?
Uniform sampling gives each \(\nabla f_i\) weight \(1/n\), which reproduces the average. The cyclic rule is deterministic, and choosing the worst point is biased.
Question 5 · Step size
SGD with a constant step on a strongly convex problem stalls at an optimality gap of about 0.08. What is the most direct way to lower that floor?
The floor \(\alpha M\sigma^2/(2m)\) depends on \(\alpha\) and the gradient noise, not on the number of iterations or the start. A larger batch would also help, by lowering \(\sigma^2\).
Question 6 · Rates
With a constant step \(\alpha\), the gradient guarantee for SGD on a smooth (possibly non-convex) function is:
\(\min_\ell \mathbb{E}\|\nabla f(x_\ell)\|^2 \le (f(x_0) - z^*)/(k\alpha) + MG^2\alpha/2\). The second term stays however long you run.
