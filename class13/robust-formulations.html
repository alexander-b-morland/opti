Robust formulations

Instead of trusting one estimate of the data, protect against every value in a set. The cost is a smaller feasible region. The reward is a solution that cannot be broken by any data in that set.

Playing against an adversary

Robust optimization takes a worst-case view of uncertainty. Think of it as a game in three moves:

1 · YouChoose a decision \(x\).
2 · AdversaryPicks the data, anywhere in the set \(\mathcal{U}\), to hurt you most.
3 · OutcomeYour \(x\) must still be feasible.
GoalThe best \(x\) that survives every move of the adversary.
Definition

The uncertainty set \(\mathcal{U}\) is the set of possible values of the uncertain parameters that the robust formulation must protect against. The modeller chooses it.

The adversary is powerful but not all-powerful. It may only choose parameter values inside \(\mathcal{U}\). Everything therefore hinges on two questions:

  • Modeling: how should \(\mathcal{U}\) be built to represent the uncertainty? (Part c.)
  • Tractability: how do we actually solve the resulting problem? (Class 14.)

The robust linear program

Nominal problem
\[ \begin{aligned} \min\ & c^\top x \\ \text{s.t. } & Ax \le b \\ & x \ge 0 \end{aligned} \]
Robust problem
\[ \begin{aligned} \min\ & c^\top x \\ \text{s.t. } & Ax \le b \quad \forall A \in \mathcal{U} \\ & x \ge 0 \end{aligned} \]

The robust problem seeks the best solution that stays feasible for every combination of the uncertain parameters in \(\mathcal{U}\). Written out, that is one constraint for each possible \(A\), so infinitely many constraints whenever \(\mathcal{U}\) is an infinite set. Class 14 shows how to turn this into a finite, solvable problem.

Uncertainty in the matrix only

What if the costs \(c\) and the right-hand sides \(b\) are uncertain too? Two small tricks move all the uncertainty into the constraint matrix.

Introduce a new variable \(t\) for the objective value (an epigraph variable):

\[ \min_{x,\, t}\ t \quad \text{s.t.}\quad c^\top x - t \le 0,\quad Ax \le b,\quad x \ge 0. \]

Now the objective \(t\) is certain, and \(c\) appears only in a constraint.

Move \(b\) to the left: \(Ax - b \le 0\). Treat \(-b\) as the coefficient column of an extra variable that is fixed to 1. Then \(b\) is just part of the matrix.

So, without loss of generality, we can study robust optimization with uncertainty in \(A\) only.

Row-wise uncertainty

In practice the uncertainty in different constraints is usually unrelated, so we assume a separate set \(\mathcal{U}_i\) for each row \(a_i\) of \(A\):

\[ \min\ c^\top x \quad \text{s.t.}\quad a_i^\top x \le b_i \quad \forall a_i \in \mathcal{U}_i,\ i = 1, \dots, m, \qquad x \ge 0. \]

Each constraint gets its own adversary, which makes the problem decompose nicely row by row.

The picture

Interactive

The robust feasible region shrinks

Maximize \(3x_1 + 4x_2\) subject to \(a_1x_1 + a_2x_2 \le 12\), \(x_1 \le 4\), \(x \ge 0\). The nominal coefficients are \((2, 3)\), but each may deviate by up to \(\rho\) times \((0.6, 0.9)\). Grow \(\rho\) and watch the region and the optimum move.

Three things to notice:

  • At \(\rho = 0\) the robust problem is the nominal one.
  • As \(\rho\) grows, the robust feasible region shrinks and the robust optimum gets worse. This loss is the price of robustness.
  • The nominal optimum lies on the nominal line. For any \(\rho > 0\) the worst case pushes its left-hand side above 12, so it becomes infeasible.

Summary

  • Robust optimization: an adversary chooses the data inside an uncertainty set \(\mathcal{U}\) chosen by the modeller, and the decision must stay feasible for every choice.
  • Uncertain costs and right-hand sides can be moved into the matrix, so we focus on uncertain \(A\).
  • With row-wise sets, each constraint \(a_i^\top x \le b_i\) must hold for all \(a_i \in \mathcal{U}_i\).
How this shows up on the exam

A common true or false: for a maximization problem with uncertain costs \(c \in \mathcal{U}\), and \(\mathcal{U}\) containing the nominal \(\bar c\), the robust value \(Z_R = \max_x \min_{c \in \mathcal{U}} c^\top x\) is at most the nominal value \(Z_N\). True: the inner minimum is at most \(\bar c^\top x\) for every \(x\). In epigraph form, the robust problem has more constraints than the nominal one.

Last year's version compared two different sets, \(\|c - \bar c\|_1 \le \rho_1\) and \(\|c - \bar c\|_\infty \le \rho_2\). Both robust values are worse than nominal, but they cannot be ranked against each other without knowing \(\rho_1\) and \(\rho_2\).
