Class 13 · Optimization under uncertainty

Robust optimization modeling

Optimal solutions are fragile when the data are estimates. Robust optimization asks for the best decision that survives every value of the data in a set you choose.

Overview

The big picture

Classes 1 to 12 assumed every number in the model was known. From class 13 on, the course asks what to do when it is not.

You are packing for a trip and the forecast says 15 degrees. Packing exactly for 15 degrees is optimal if the forecast is right, and miserable if it is off by five. A sensible traveller packs for any temperature between 10 and 20, and accepts carrying a slightly heavier bag.

The range 10 to 20 is the uncertainty set. The heavier bag is the price of robustness. Robust optimization makes both precise.

\[ \min_x\ c^\top x \quad \text{s.t.}\quad a_i^\top x \le b_i \quad \forall\, a_i \in \mathcal{U}_i,\ i = 1, \dots, m. \]

Every constraint must hold for every possible value of its coefficients in the set \(\mathcal{U}_i\). Class 13 is about choosing the sets. Class 14 is about solving the problem.

In real linear programs, coefficient errors of 0.1% can produce constraint violations of 500%. Probability models would need distributions nobody has. Robust optimization only needs a set, keeps the problem tractable, and often costs very little optimality.

The story of the class in three steps

13a · ProblemTiny data errors break optimal solutions.
13b · ModelAn adversary picks the data from a set. Stay feasible for all of it.
13c · SetsBox or CLT set, and the price of robustness.
Four takeaways from the lecture
  1. Robust optimization is a tractable way to find decisions that are immune to data uncertainty, estimation errors and implementation errors.
  2. It protects against adversarial perturbations of the parameters within an uncertainty set.
  3. The set is built from the conclusions of probability theory, not its axioms, so it needs no distributional assumptions.
  4. The price of robustness is often small: give up a little optimality, stay feasible for a wide range of outcomes.

For your note sheet

Robust LP\(\min c^\top x\) s.t. \(a_i^\top x \le b_i\ \forall a_i \in \mathcal{U}_i\).
Uncertain \(c\): epigraph \(t \ge c^\top x\). Uncertain \(b\): move it into \(A\).
Box set\(|a_i - \bar a_i| \le \Gamma\sigma_i\) for each \(i\).
With \(x \ge 0\): \(\sum_i (\bar a_i + \Gamma\sigma_i)x_i \le b\).
CLT set\(\big|\sum_i (a_i - \bar a_i)/\sigma_i\big| \le \Gamma\sqrt{n}\).
\(\Gamma = 2\): about 95%. \(\Gamma = 3\): about 99.7%.
Trade-offBigger set: more feasible in reality, worse objective. Robust value is never better than nominal (if \(\bar a \in \mathcal{U}\)).

Exam practice

Test yourself

Multiple choice in the style of the midterm. Say your one-line justification before you click.

Question 1 · Robust value
A maximization LP has uncertain costs \(c \in \mathcal{U}\), where \(\mathcal{U}\) contains the nominal \(\bar c\). Compare the nominal value \(Z_N\) with the robust value \(Z_R = \max_{Ax \le b} \min_{c \in \mathcal{U}} c^\top x\).
For every \(x\), \(\min_{c \in \mathcal{U}} c^\top x \le \bar c^\top x\) because \(\bar c\) is in the set. Taking the maximum over \(x\) on both sides gives \(Z_R \le Z_N\).
Question 2 · Comparing sets
A minimization problem with uncertain \(c\) is solved with \(\mathcal{U}_1 = \{c : \|c - \bar c\|_1 \le \rho_1\}\) and with \(\mathcal{U}_2 = \{c : \|c - \bar c\|_\infty \le \rho_2\}\). Which is true?
Both sets contain \(\bar c\), so both robust problems are at least as constrained as the nominal one. Which set is larger depends on \(\rho_1\) and \(\rho_2\), so neither ordering holds in general.
Question 3 · Monotonicity
In the capacity expansion example, what happens to the NPV of the robust solution as \(\Gamma\) increases?
A larger \(\Gamma\) gives a larger uncertainty set, which removes feasible plans. The best NPV over a smaller set of plans cannot be higher.
Question 4 · Box worst case
Constraint \(a_1x_1 + a_2x_2 \le 10\) with \(x \ge 0\), \(\bar a = (2, 3)\), and box set \(|a_i - \bar a_i| \le 1\). The robust constraint is:
With \(x \ge 0\), the adversary raises every coefficient to its maximum, \(a = (3, 4)\).
Question 5 · Philosophy
Which statement best describes how robust optimization treats uncertainty?
Robust optimization is a worst-case approach over a set. No distribution is assumed, though results like the CLT can guide how the set is shaped.
Question 6 · CLT set
Why does the CLT set usually give a less conservative solution than the box set with the same \(\Gamma\)?
The CLT set limits the total deviation, reflecting that independent errors tend to cancel. It is not a subset of the box in general, since one parameter alone may deviate by more than \(\Gamma\sigma_i\), but it removes the "everything goes wrong together" scenarios that drive the box solution.
