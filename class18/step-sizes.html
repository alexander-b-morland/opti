Step sizes, starts and scaling

The theorems assume \(\alpha = 1/M\), but in practice nobody hands you \(M\). This part is about the choices that decide whether gradient descent takes twenty iterations or twenty thousand.

The step-size trade-off

Every step-size choice balances two failure modes:

  • Too small: each iteration makes little progress, and convergence is slow.
  • Too large: the first-order approximation stops being accurate, the iterate overshoots, and the method can oscillate or diverge.

Somewhere in between, convergence is fastest. Where exactly depends on the local curvature of \(f\), which changes from point to point and from direction to direction.

Beyond the slides: the exact stability limit for a quadratic

For \(f(x) = \tfrac12 x^\top Q x - c^\top x\) with \(Q \succ 0\), the gradient is \(Qx - c = Q(x - x^*)\). A constant step gives

\[ x_{k+1} - x^* = (I - \alpha Q)(x_k - x^*). \]

Along each eigenvector of \(Q\) with eigenvalue \(\lambda_i\), the error is multiplied by \(1 - \alpha\lambda_i\) every step. It shrinks if and only if \(|1 - \alpha\lambda_i| < 1\), so the method converges from every start exactly when \(0 < \alpha < 2/\lambda_{\max}\). The best constant step is \(\alpha = 2/(\lambda_{\min} + \lambda_{\max})\), which balances the slowest and the fastest direction. Its error factor is \((\kappa - 1)/(\kappa + 1)\).

Four step-size rules

\[ \alpha_k = s \quad \text{for all } k. \]

Simplest possible. Works well if \(s\) is tuned to the problem, for example \(s = 1/M\) when \(M\) is known. Too large and it diverges. Too small and it crawls.

\[ \alpha_k \to 0 \qquad \text{and} \qquad \sum_{k=0}^\infty \alpha_k = \infty. \]

For example \(\alpha_k = 1/k\). The steps shrink, so the method eventually settles down. But not too fast: the infinite sum ensures the iterates can still travel any distance. This rule becomes important for stochastic gradient descent in class 20.

\[ \alpha_k \in \arg\min_{\alpha \ge 0} f(x_k + \alpha d_k). \]

Go as far along the direction as is useful, and stop exactly where \(f\) is lowest on that line. Best possible progress per iteration, but each iteration solves a one-dimensional optimization problem (for example by bisection). For a quadratic there is a closed form.

Start with a trial step \(\alpha = s\). Accept it if it gives a sufficient decrease:

\[ f(x_k + \alpha d_k) \le f(x_k) + \sigma\,\alpha\,\nabla f(x_k)^\top d_k, \qquad 0 < \sigma < \tfrac12. \]

Otherwise shrink it, \(\alpha \leftarrow \beta\alpha\) with \(0 < \beta < 1\), and test again. The accepted step is \(\alpha_k = s\beta^{m_k}\), where \(m_k\) is the number of shrinks. The test asks for a decrease of at least a fraction \(\sigma\) of what the tangent line promises, which rules out steps that barely help.

The starting point

For a convex function, the starting point only affects how long the trip takes. For a non-convex function it can decide where the trip ends. Gradient descent finds a stationary point near where it starts, and that may be a poor local minimum.

A simple remedy from the lecture: run the algorithm in parallel from several starting points and keep the best result. Step size and starting point can also be tuned together. A larger step sometimes jumps over a shallow local minimum that a small step would get stuck in, though with no guarantee.

The condition number

Definition

For a symmetric positive definite matrix \(Q\), the condition number is the ratio of its largest to its smallest eigenvalue:

\[ \kappa(Q) = \frac{\lambda_{\max}(Q)}{\lambda_{\min}(Q)} \ge 1. \]
Theorem (Kantorovich)

If \(f(x) = \tfrac12 x^\top Q x - c^\top x + b\) with \(Q \succ 0\), and gradient descent uses exact line search, then

\[ f(x_{k+1}) - z^* \le \left( \frac{\kappa(Q) - 1}{\kappa(Q) + 1} \right)^2 \big(f(x_k) - z^*\big). \]

Two matrices from the lecture show how much this matters:

\(Q\)\(\kappa(Q)\)Factor per iterationCharacter
\(\begin{pmatrix} 20 & 5 \\ 5 & 16 \end{pmatrix}\)1.85\(\approx 0.09\)Well-conditioned. Each step removes about 91% of the gap.
\(\begin{pmatrix} 20 & 5 \\ 5 & 2 \end{pmatrix}\)30.2\(\approx 0.88\)Ill-conditioned. Each step removes only about 12% of the gap.

With large \(\kappa\) the level sets are long, thin ellipses. The gradient is perpendicular to the level set, so it points mostly across the valley rather than along it. With exact line search, each new gradient is perpendicular to the previous step, so the path turns 90 degrees at every iteration. The result is a zigzag that makes slow progress down the valley.

Beyond quadratics, the same role is played by the condition number of the Hessian. The linear rate of part c has constant \(c = 1 - m/M\), and \(M/m\) bounds the condition number of \(\nabla^2 f(x)\) everywhere. Large \(\kappa\) means \(c\) close to 1, which means slow convergence, whichever step-size rule you use.

Diagonal scaling

Bad conditioning often comes from bad units. If \(x_1\) is a length in kilometres and \(x_2\) a similar length in millimetres, the function is extremely steep in one variable and flat in the other, for no good reason. Change units and the problem becomes easy.

Formally, substitute \(x = Sy\) for a nonsingular diagonal \(S\), and run gradient descent on \(g(y) = f(Sy)\). Since \(\nabla g(y) = S^\top \nabla f(Sy)\),

\[ y_{k+1} = y_k - \alpha_k S^\top \nabla f(Sy_k) \quad\Longrightarrow\quad Sy_{k+1} = Sy_k - \alpha_k S S^\top \nabla f(Sy_k). \]

Back in the original variables this is scaled gradient descent:

\[ x_{k+1} = x_k - \alpha_k D \nabla f(x_k), \qquad D = SS^\top \succ 0 \text{ diagonal}. \]

The lecture's example: \(f(x) = 500x_1^2 + 20x_1x_2 + 0.5x_2^2\), so \(Q = \begin{pmatrix} 1000 & 20 \\ 20 & 1 \end{pmatrix}\) with \(\kappa(Q) \approx 1{,}668\). Choosing \(D = \mathrm{diag}(1/1000, 1)\), which divides each variable by its own curvature, gives \(\kappa(D^{1/2}QD^{1/2}) \approx 4.4\). On the slides, plain gradient descent takes 68 iterations and scaled gradient descent 20.

Steepest descent in other norms

Part b showed that \(-\nabla f\) is the steepest direction when "length" means the Euclidean norm. Choose a different norm and you get a different method.

Definition (steepest descent)

For any norm \(\|\cdot\|\), the steepest descent direction is

\[ d_k \in \arg\min\big\{ \nabla f(x_k)^\top v : \|v\| = 1 \big\}, \]

the unit-length direction with the largest first-order decrease, since \(f(x + v) \approx f(x) + \nabla f(x)^\top v\).

Summary

  • Step size: too small is slow, too large is unstable. Constant, diminishing, exact line search and backtracking are the standard rules.
  • Exact line search: fewer, more expensive iterations. Backtracking: more, cheaper iterations.
  • Non-convex \(f\): the start decides which local minimum you reach. Use several starts.
  • The condition number \(\kappa\) controls speed. Large \(\kappa\) means narrow valleys and zigzagging.
  • Diagonal scaling is a change of units that reduces \(\kappa\). Steepest descent in the \(P\)-norm is scaled gradient descent, and in the 1-norm it is coordinate descent.
How this shows up on the exam

"The larger the step size, the faster the convergence" is a favourite statement to judge. The right answer is that we do not know in general: larger steps help only while the function keeps decreasing along the direction.

You may also be shown contour plots with iterate paths and asked to match each to a method. A zigzag across a narrow valley is gradient descent. Wobbly, noisy paths are stochastic gradient descent (class 20). Very few, direct steps are Newton's method (class 19).

Check yourself
Quick check
You use backtracking with \(s = 1\), \(\beta = 0.5\). The test fails for \(\alpha = 1\) and \(\alpha = 0.5\), and passes for \(\alpha = 0.25\). What is \(\alpha_k\)?
Backtracking accepts the first trial step that passes: \(\alpha_k = s\beta^2 = 0.25\). It does not look for the best step. That is exact line search.
Quick check
\(f(x) = 50x_1^2 + 0.5x_2^2\). Which diagonal \(D\) makes scaled gradient descent best conditioned?
The Hessian is \(\mathrm{diag}(100, 1)\), with \(\kappa = 100\). Dividing each coordinate by its curvature gives \(D^{1/2} Q D^{1/2} = I\), with \(\kappa = 1\). Multiplying by 100 would make things far worse.
