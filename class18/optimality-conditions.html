Optimality conditions

Before running an algorithm, we need to know what we are looking for. A flat spot is necessary for a minimum, but it is not enough. Curvature and convexity decide the rest.

Local and global minima

We study \(\min_{x \in \mathbb{R}^n} f(x)\) where \(f\) is continuous and, for this class, twice continuously differentiable. Two kinds of minimum matter.

Definitions

\(x^*\) is a global minimum if \(f(x^*) \le f(x)\) for every \(x \in \mathbb{R}^n\).

\(x^*\) is a local minimum if there is a radius \(\varepsilon > 0\) such that \(f(x^*) \le f(x)\) for every \(x\) with \(\|x - x^*\| \le \varepsilon\). It is a strict local minimum if the inequality is strict for \(x \neq x^*\).

Algorithms only ever look at a small neighbourhood of the current point, so local information is all they can use. The whole of this part is about what local information can tell you, and what it cannot.

The two tools: gradient and Hessian

The gradient collects the first partial derivatives. It points in the direction in which \(f\) increases fastest, and its length is that rate of increase.

\[ \nabla f(x) = \left( \frac{\partial f}{\partial x_1}(x), \dots, \frac{\partial f}{\partial x_n}(x) \right) \]

The Hessian collects the second partial derivatives. It is a symmetric \(n \times n\) matrix that describes curvature: how the slope itself changes as you move.

\[ \nabla^2 f(x) = \left[ \frac{\partial^2 f}{\partial x_i \, \partial x_j}(x) \right]_{i,j = 1}^n \]

Together they give the second-order Taylor expansion, which is the source of every result in this part:

\[ f(x + d) \approx f(x) + \nabla f(x)^\top d + \tfrac12 \, d^\top \nabla^2 f(x) \, d \]

Read it as: the value nearby equals the value here, plus a slope term that is linear in the step, plus a curvature term that is quadratic in the step. For small steps, the slope term dominates. Only when the slope term vanishes does the curvature term get the final word.

Necessary conditions: what every minimum satisfies

Theorem (necessary conditions)

Let \(f\) be twice continuously differentiable. If \(x^*\) is a local minimum, then

\[ \nabla f(x^*) = 0 \qquad \text{and} \qquad \nabla^2 f(x^*) \succeq 0. \]

\(\nabla^2 f(x^*) \succeq 0\) means the Hessian is positive semidefinite: \(u^\top \nabla^2 f(x^*) u \ge 0\) for every vector \(u\). In words, \(f\) does not curve downward in any direction.

If the gradient were not zero, you could take a tiny step against it and go downhill. So a minimum must be flat. And if the function curved downward in some direction, a tiny step along that direction would also go downhill. So a minimum cannot curve down anywhere.

Fix any direction \(d\). Because \(x^*\) is a local minimum, for every small enough \(\alpha > 0\):

\[ \frac{f(x^* + \alpha d) - f(x^*)}{\alpha} \ge 0. \]

Let \(\alpha \to 0\). The left side becomes the directional derivative, so \(\nabla f(x^*)^\top d \ge 0\) for every \(d\). Apply this to \(d = e_i\) and \(d = -e_i\). Both \(\partial_i f(x^*) \ge 0\) and \(-\partial_i f(x^*) \ge 0\), so \(\partial_i f(x^*) = 0\) for every \(i\).

Use the Taylor expansion with remainder. There is a function \(\varepsilon(\cdot)\) with \(\varepsilon(y) \to 0\) as \(y \to 0\) such that

\[ f(x^* + \alpha d) - f(x^*) = \alpha \underbrace{\nabla f(x^*)^\top d}_{=0} + \frac{\alpha^2}{2} d^\top \nabla^2 f(x^*) d + \alpha^2 \|d\|^2 \varepsilon(\alpha d). \]

The left side is \(\ge 0\) for small \(\alpha\). Divide by \(\alpha^2\) and let \(\alpha \to 0\). The remainder vanishes, and we are left with \(d^\top \nabla^2 f(x^*) d \ge 0\) for every \(d\).

A point with \(\nabla f(x) = 0\) is called a stationary point. Every local minimum is stationary, but so is every local maximum and every saddle point. Stationary points are candidates, nothing more.

The sufficient condition: when you can be sure

Theorem (sufficient condition)

Let \(f\) be twice continuously differentiable. If

\[ \nabla f(x^*) = 0 \qquad \text{and} \qquad \nabla^2 f(x^*) \succ 0, \]

then \(x^*\) is a strict local minimum.

\(\nabla^2 f(x^*) \succ 0\) means positive definite: \(u^\top \nabla^2 f(x^*) u > 0\) for every \(u \neq 0\). The function curves strictly upward in every direction.

Proof sketch

The Hessian is continuous, so it stays positive definite in a small ball \(\|x - x^*\| \le \varepsilon\). By Taylor's theorem with the mean-value form of the remainder, for any \(\|y\| \le \varepsilon\) there is a point \(z = ty\) with \(t \in [0, 1]\) such that

\[ f(x^* + y) - f(x^*) = \underbrace{\nabla f(x^*)^\top y}_{=0} + \tfrac12 \underbrace{y^\top \nabla^2 f(x^* + z)\, y}_{>0 \text{ for } y \neq 0}. \]

So \(f(x^* + y) > f(x^*)\) for every nonzero \(y\) in the ball.

Notice the gap between the two theorems. Necessary asks for \(\succeq 0\). Sufficient asks for \(\succ 0\). When the Hessian is positive semidefinite but singular, second-order information cannot decide. Explore the gap below.

The key lesson

\(x^3\) and \(x^4\) have the same first and second derivatives at 0. One has a minimum there and one does not. When \(f''(x^*) = 0\) (or the Hessian is singular), you must look beyond second-order information, for example by evaluating \(f\) at nearby points.

Reading a Hessian

In practice the question is always: is this symmetric matrix positive definite, positive semidefinite or indefinite? The eigenvalues answer it.

Eigenvalues of \(\nabla^2 f(x^*)\)NameConclusion at a stationary point
All \(> 0\)Positive definite, \(\succ 0\)Strict local minimum
All \(\ge 0\), some \(= 0\)Positive semidefinite, singularInconclusive. Could be a minimum or not.
Some \(> 0\), some \(< 0\)IndefiniteSaddle point. Not a local minimum.
All \(< 0\)Negative definite, \(\prec 0\)Strict local maximum

For a \(2 \times 2\) symmetric matrix \(\begin{pmatrix} a & b \\ b & c \end{pmatrix}\) there is a shortcut that avoids computing eigenvalues. The determinant is the product of the eigenvalues and the trace is their sum.

  • \(\det = ac - b^2 > 0\) and \(a > 0\): both eigenvalues positive, so positive definite.
  • \(\det < 0\): eigenvalues of opposite sign, so indefinite.
  • \(\det = 0\): at least one eigenvalue is zero, so singular.

Two worked examples from the lecture

Example 1: two candidates, one minimum

\[ f(x) = \tfrac12 x_1^2 + x_1 x_2 + 2 x_2^2 - 4x_1 - 4x_2 - x_2^3 \]

Step 1, gradient.

\[ \nabla f(x) = \begin{pmatrix} x_1 + x_2 - 4 \\ x_1 + 4x_2 - 4 - 3x_2^2 \end{pmatrix} \]

Step 2, solve \(\nabla f = 0\). The first equation gives \(x_1 = 4 - x_2\). Substituting into the second gives \(3x_2 - 3x_2^2 = 0\), so \(x_2 = 0\) or \(x_2 = 1\). The candidates are \((4, 0)\) and \((3, 1)\).

Step 3, Hessian.

\[ \nabla^2 f(x) = \begin{pmatrix} 1 & 1 \\ 1 & 4 - 6x_2 \end{pmatrix} \]

Step 4, classify. At \((4, 0)\) the Hessian is \(\begin{pmatrix} 1 & 1 \\ 1 & 4 \end{pmatrix}\), with \(a = 1 > 0\) and \(\det = 3 > 0\). Positive definite, so a strict local minimum. At \((3, 1)\) it is \(\begin{pmatrix} 1 & 1 \\ 1 & -2 \end{pmatrix}\) with \(\det = -3 < 0\). Indefinite, so a saddle point.

Is \((4, 0)\) a global minimum? No. The \(-x_2^3\) term sends \(f\) to \(-\infty\) as \(x_2 \to +\infty\), so there is no global minimum at all. Local tests cannot see that.

Example 2: the test passes, the point fails

\[ f(x) = x_1^3 + x_2^2, \qquad \nabla f(x) = \begin{pmatrix} 3x_1^2 \\ 2x_2 \end{pmatrix}, \qquad \nabla^2 f(x) = \begin{pmatrix} 6x_1 & 0 \\ 0 & 2 \end{pmatrix} \]

The only stationary point is \((0, 0)\), where the Hessian is \(\begin{pmatrix} 0 & 0 \\ 0 & 2 \end{pmatrix} \succeq 0\). Both necessary conditions hold. Yet \(f(-\varepsilon, 0) = -\varepsilon^3 < 0 = f(0, 0)\), so it is not a local minimum. This is the two-dimensional version of \(x^3\).

The convex case: every flat point is the bottom

Recall the two characterisations of convexity for differentiable functions:

Reminder: convexity tests

First-order: \(f\) is convex if and only if \(f(y) \ge f(x) + \nabla f(x)^\top (y - x)\) for all \(x, y\). The tangent plane lies below the graph everywhere.

Second-order: a twice continuously differentiable \(f\) is convex if and only if \(\nabla^2 f(x) \succeq 0\) for all \(x\).

Theorem

Let \(f\) be convex and continuously differentiable. Then \(x^*\) is a global minimum if and only if \(\nabla f(x^*) = 0\).

The proof is one line. Plug \(\nabla f(x^*) = 0\) into the first-order condition: \(f(y) \ge f(x^*) + 0\) for every \(y\).

Why this matters for algorithms

Gradient descent searches for a point where the gradient vanishes. For a convex function, finding one means you are done, globally. For a non-convex function, you may have found a local minimum, a saddle point, or something worse, and in general finding the global minimum is very hard.

Note the difference between the second-order tests. The sufficient condition checks the Hessian at one point and gives a local conclusion. Convexity requires \(\nabla^2 f \succeq 0\) everywhere and gives a global conclusion.

Example: ridge regression

Fit coefficients \(\beta \in \mathbb{R}^m\) to data \(X \in \mathbb{R}^{n \times m}\), \(y \in \mathbb{R}^n\), with an \(\ell_2\) penalty \(\lambda > 0\) that discourages large coefficients:

\[ f(\beta) = \frac12 \sum_{i=1}^n \Big( y_i - \sum_{j=1}^m x_{ij} \beta_j \Big)^2 + \frac{\lambda}{2} \sum_{j=1}^m \beta_j^2 = \frac12 \|y - X\beta\|^2 + \frac{\lambda}{2}\|\beta\|^2. \]

Differentiate:

\[ \nabla f(\beta) = -X^\top (y - X\beta) + \lambda \beta, \qquad \nabla^2 f(\beta) = X^\top X + \lambda I. \]

The Hessian is positive definite everywhere, because for any \(u \neq 0\)

\[ u^\top (X^\top X + \lambda I) u = \|Xu\|^2 + \lambda \|u\|^2 > 0. \]

So \(f\) is convex (in fact strongly convex), and the unique stationary point is the global minimum. Setting the gradient to zero gives the closed form

\[ \beta^* = (X^\top X + \lambda I)^{-1} X^\top y. \]

With millions of features, inverting \(X^\top X + \lambda I\) is too expensive. That is where gradient descent comes in, in part b.

Summary

  • A local minimum can only occur at a stationary point, \(\nabla f(x) = 0\).
  • Convex \(f\): any stationary point is a global minimum.
  • Otherwise, look at the Hessian at the stationary point. Positive definite: local minimum. Positive semidefinite and singular: may or may not be one. Indefinite: not a local minimum.
  • In non-convex optimization, finding the global minimum is very hard.
How this shows up on the exam

Last year's second midterm opened with exactly this trap: given only \(\nabla f(x^*) = 0\), is \(x^*\) a global minimum, a local minimum, or not necessarily either? Answer: not necessarily a local minimum, with \(x^3\) as the counterexample.

A second classic: for a constrained problem such as a linear program, the optimum usually has \(\nabla f(x^*) = c \neq 0\). The condition \(\nabla f = 0\) is for unconstrained problems only.

A longer question asked you to prove that a convex, differentiable \(f\) that is minimized along each coordinate separately at \(x^*\) is globally minimized there. Each coordinate-wise minimum gives \(\partial f/\partial x_i (x^*) = 0\), so \(\nabla f(x^*) = 0\), and convexity finishes the job. Without differentiability this fails: \(f(x) = \max\{x_1, x_2\} + |x_1 - x_2|\) is minimized along both axes at the origin, but \(f(-1, -1) = -1 < 0\).
