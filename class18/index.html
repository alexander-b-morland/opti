Overview

The big picture

Class 17 showed how to write down non-linear models. Class 18 starts solving them, beginning with the simplest case: no constraints at all.

\[ \min_{x \in \mathbb{R}^n} f(x), \qquad z^* = \min_x f(x), \qquad x^* \in \arg\min_x f(x) \]

Here \(f\) is a smooth function of \(n\) variables. Least-squares regression, fitting a machine-learning model and smoothing a noisy signal all look like this. Constrained problems are harder, but the algorithms for them are built on top of the ideas in this class.

You are standing on a hillside in thick fog and want to reach the lowest point of the valley. You cannot see the valley. You can only feel the slope under your feet. The sensible plan is to step in the direction that goes down most steeply, check the slope again, and repeat.

That is gradient descent. The gradient \(\nabla f(x)\) points in the direction of steepest ascent, so you walk in the direction \(-\nabla f(x)\). Three questions follow immediately. How do you know you have arrived? How long should each step be? And how many steps will it take?

\[ x_{k+1} = x_k - \alpha_k \nabla f(x_k) \]

Start somewhere, compute the gradient, take a step of length \(\alpha_k\) against it, and repeat until the gradient is close to zero. Everything else in this class is about when this simple loop works and how fast.

Gradient descent is the workhorse of modern machine learning. Every neural network is trained with a variant of it (class 19). It needs only first derivatives, so each iteration is cheap even with millions of variables. The price is that it can be slow when the function is badly shaped, and that it can stop at a local minimum when the function is not convex.

Four takeaways from the lecture
  1. Unconstrained minimization is the core problem of non-linear optimization.
  2. Descent methods find stationary points, which are only candidates. With convexity, any stationary point is a global minimum. Without it, global optimization is much harder.
  3. Gradient descent converges sub-linearly under convexity and linearly under strong convexity.
  4. Speed depends on the step size (which you choose) and on the shape of \(f\) (which you do not).

Exam practice

Test yourself

Multiple choice in the style of the midterm. On the exam you also write a one-line justification, so say yours out loud before you click.

Question 1 · Optimality
Let \(f\) be differentiable and suppose \(\nabla f(x^*) = 0\). Which statement is true?
A zero gradient only makes \(x^*\) a candidate. \(f(x) = x^3\) has \(f'(0) = 0\), but 0 is neither a minimum nor a maximum.
Question 2 · Optimality
At a stationary point the Hessian is \(\begin{pmatrix} 2 & 3 \\ 3 & 2 \end{pmatrix}\). What is the point?
The determinant is \(4 - 9 = -5 < 0\), so the eigenvalues (5 and \(-1\)) have opposite signs. The Hessian is indefinite, which violates the second-order necessary condition. Positive diagonal entries are not enough.
Question 3 · Convexity
\(f\) is convex and differentiable, and \(\nabla f(x^*) = 0\). Then:
The convexity inequality \(f(y) \ge f(x^*) + \nabla f(x^*)^\top (y - x^*) = f(x^*)\) gives a global minimum directly. Uniqueness needs more, for example strict or strong convexity. A constant function is convex, and every point minimizes it.
Question 4 · Algorithm
True or false: gradient descent is a descent algorithm, meaning \(f(x_{k+1}) < f(x_k)\), provided the step size is small enough and \(\nabla f(x_k) \neq 0\).
By a first-order expansion, \(f(x_k - \alpha \nabla f(x_k)) \approx f(x_k) - \alpha \|\nabla f(x_k)\|^2\), which is smaller than \(f(x_k)\) for small \(\alpha > 0\).
Question 5 · Step size
You run gradient descent with a constant step size on a differentiable function. Which is true?
Larger steps make more progress per iteration only while the first-order approximation stays accurate. Too large a step overshoots and can diverge. Too small a step crawls. The best step depends on the local curvature.
Question 6 · Rates
\(f\) is convex and \(M\)-smooth, but not strongly convex. Gradient descent with \(\alpha = 1/M\) converges:
The theorem gives \(f(x_k) - z^* \le M\|x_0 - x^*\|^2/(2k)\). Halving the error needs twice as many iterations, so accuracy \(\varepsilon\) takes \(O(1/\varepsilon)\) iterations.
Question 7 · Rates
\(f\) is \(m\)-strongly convex and \(M\)-smooth. A variant of gradient descent guarantees \(f(x_{k+1}) - z^* \le \left(1 - \tfrac{m}{2M}\right)(f(x_k) - z^*)\). Compared with standard gradient descent with \(\alpha = 1/M\), it:
The ratio of consecutive gaps is bounded by a constant below 1, so the rate is linear. The constant \(1 - m/(2M)\) is closer to 1 than \(1 - m/M\), so the guarantee is weaker.
Question 8 · Stability
Gradient descent with a constant step on \(f(x) = \tfrac12 x^\top Q x\), where the eigenvalues of \(Q\) are 1 and 10. Which step size makes the iterates diverge from most starting points?
The error is multiplied by \(I - \alpha Q\) each step, with eigenvalues \(1 - \alpha\) and \(1 - 10\alpha\). Stability needs \(|1 - 10\alpha| < 1\), so \(\alpha < 2/10 = 0.2\). At \(\alpha = 0.25\) the factor is \(-1.5\), and that component grows.
Question 9 · Conditioning
You minimize \(f(x) = \tfrac12 x^\top Q x - c^\top x\) with \(Q = 4I\) using gradient descent with exact line search. How many iterations does it take?
With \(\kappa(Q) = 1\) the level sets are circles, so \(-\nabla f(x_0)\) points straight at \(x^*\). Exact line search stops exactly there. The Kantorovich factor \(\left(\tfrac{\kappa - 1}{\kappa + 1}\right)^2\) equals 0.
Question 10 · Scaling
One variable is measured in kilometres and another in millimetres. Gradient descent zigzags badly. The cleanest fix from the lecture is to:
Diagonal scaling is a change of units. It shrinks the condition number of the Hessian. A smaller step only makes the zigzag slower.
Question 11 · Steepest descent
Steepest descent with respect to the 1-norm, \(d_k \in \arg\min\{\nabla f(x_k)^\top v : \|v\|_1 = 1\}\), is equivalent to:
Over the 1-norm ball, a linear function is minimized at a corner, \(\pm e_i\). The best corner is the coordinate with the largest \(|\partial f/\partial x_i|\). The 2-norm gives ordinary gradient descent.
Question 12 · Regression
Ridge regression minimizes \(f(\beta) = \tfrac12 \|y - X\beta\|^2 + \tfrac{\lambda}{2}\|\beta\|^2\) with \(\lambda > 0\). Which statement is true?
\(u^\top (X^\top X + \lambda I) u = \|Xu\|^2 + \lambda \|u\|^2 > 0\) for \(u \neq 0\), whatever the rank of \(X\). Setting the gradient to zero gives \(\beta^* = (X^\top X + \lambda I)^{-1} X^\top y\).
