A generic descent method

Since we cannot solve \(\nabla f(x) = 0\) by hand for most functions, we improve a guess step by step. Every method in classes 18 to 20 fits this template:

Algorithm · generic descent method
  1. Choose a starting point \(x_0 \in \mathbb{R}^n\). Set \(k = 0\).
  2. Repeat until a stopping criterion holds, for example \(\|\nabla f(x_k)\| \le \varepsilon\):
    1. Pick a descent direction \(d_k\), meaning \(\nabla f(x_k)^\top d_k < 0\).
    2. Pick a step size \(\alpha_k > 0\).
    3. Update \(x_{k+1} = x_k + \alpha_k d_k\).
    4. Set \(k \leftarrow k + 1\).

Why does \(\nabla f(x_k)^\top d_k < 0\) guarantee progress? By the first-order Taylor expansion,

\[ f(x_k + \alpha_k d_k) \approx f(x_k) + \alpha_k \underbrace{\nabla f(x_k)^\top d_k}_{< 0} < f(x_k). \]

The approximation is accurate when \(\alpha_k\) is small. So any direction that makes an acute angle with \(-\nabla f(x_k)\) lowers \(f\), as long as the step is short enough. Methods differ in two choices: which direction (gradient, Newton, stochastic gradient) and which step size.

The questions for any such method are always the same. Does it converge to a stationary point? Under which conditions? At what rate?

Gradient descent

The most natural descent direction is the negative gradient itself.

Algorithm · gradient descent
  1. Choose \(x_0\). Set \(k = 0\).
  2. Repeat until a stopping criterion holds:
    1. \(d_k = -\nabla f(x_k)\).
    2. Pick a step size \(\alpha_k > 0\).
    3. \(x_{k+1} = x_k - \alpha_k \nabla f(x_k)\).
    4. \(k \leftarrow k + 1\).

It is a valid descent direction whenever we are not already at a stationary point:

\[ \nabla f(x_k)^\top d_k = -\|\nabla f(x_k)\|^2 < 0 \quad\Longrightarrow\quad f(x_{k+1}) \approx f(x_k) - \alpha_k \|\nabla f(x_k)\|^2 < f(x_k). \]

So with small enough steps, gradient descent produces a strictly decreasing sequence \(f(x_0) > f(x_1) > f(x_2) > \cdots\). Under further assumptions (part c), the iterates converge to a stationary point, and to a global minimum when \(f\) is convex.

With one variable the rule is \(x_{k+1} = x_k - \alpha f'(x_k)\). If the slope is negative, \(f\) decreases to the right, and \(-\alpha f'(x_k) > 0\) moves you right. If the slope is positive, you move left. The steeper the slope, the bigger the move.

In two or more dimensions the gradient is perpendicular to the level set (contour line) through \(x_k\). Gradient descent therefore always steps straight across the contour lines, in the downhill direction. That is the locally steepest way down, but not necessarily the most direct route to the minimum. Part d shows how this causes zigzagging.

Among all directions of length one, which decreases \(f\) fastest to first order? We want to minimize \(\nabla f(x)^\top v\) subject to \(\|v\|_2 = 1\). By the Cauchy-Schwarz inequality, \(\nabla f(x)^\top v \ge -\|\nabla f(x)\|\), with equality for \(v = -\nabla f(x)/\|\nabla f(x)\|\). So the negative gradient is the direction of steepest descent in the Euclidean norm. Other norms give other methods (part d).

Watch it step

Interactive

Gradient descent on \(f(x) = \tfrac14 x^4 - x^2 + 0.4x\)

The dashed line is the tangent at the current point. The red arrow is the next move, \(-\alpha f'(x_k)\). Step through, then try a large step size and a start point on the right.

Three things to notice:

  • Steps shrink automatically. Near the bottom the slope is small, so \(\alpha |f'(x_k)|\) is small, even with a constant \(\alpha\).
  • Too large a step overshoots. Push \(\alpha\) towards 0.9 and the iterates bounce across the valley or fly off. Small enough \(\alpha\) is part of the descent guarantee.
  • Where you start decides where you end. Starting at \(x_0 = 1.9\), you land in the right-hand valley, which is only a local minimum. The function is not convex, so gradient descent has no way of knowing a better valley exists.

Gradient descent for regression

Back to ridge regression from part a, \(f(\beta) = \tfrac12 \|y - X\beta\|^2 + \tfrac{\lambda}{2}\|\beta\|^2\), with gradient \(\nabla f(\beta) = -X^\top (y - X\beta) + \lambda \beta\). Written coefficient by coefficient, the update is

\[ \beta_j^{k+1} = \beta_j^k + \alpha \left( \sum_{i=1}^n x_{ij} \Big( y_i - \sum_{l=1}^m x_{il} \beta_l^k \Big) - \lambda \beta_j^k \right). \]

Read the bracket as feedback. \(y_i - \sum_l x_{il}\beta_l^k\) is the current residual for data point \(i\). If the model under-predicts (positive residual) on points where feature \(j\) is positive, coefficient \(\beta_j\) goes up. The \(-\lambda \beta_j^k\) term pulls every coefficient back towards zero. Each iteration is a small model adjustment based on how well the current fit performs, repeated until progress becomes negligible.

Because the ridge loss is convex, gradient descent is guaranteed to reach the global minimum. How fast is another matter. The lecture's example predicts wine prices from 46 samples and 7 features, and compares small, large and optimized step sizes. The loss curves differ a lot, for both small and large \(\lambda\). Speed is a matter of algorithm design, which is what parts c and d are about.

Rates of convergence

To compare algorithms we need a language for speed. Let \(z_k\) be a sequence converging to \(z^*\). It could be the iterates \(x_k\) or the values \(f(x_k)\).

Definition

The sequence has order \(p\) and rate \(\beta\) if

\[ \lim_{k \to \infty} \frac{|z_{k+1} - z^*|}{|z_k - z^*|^p} = \beta. \]
NameConditionExampleWhat it feels like
Sub-linear\(p = 1,\ \beta = 1\)\(z_k = 1/k\)Progress keeps slowing down. Ten times more accuracy costs ten times more iterations.
Linear\(p = 1,\ 0 < \beta < 1\)\(z_k = a^k,\ a < 1\)The error shrinks by a constant factor each step. A fixed number of correct digits gained per iteration.
Super-linear\(p = 1,\ \beta = 0\)\(z_k = (1/k)^k\)The shrink factor itself tends to zero. Faster than any linear rate.
Quadratic\(p = 2\)\(z_k = a^{2^k},\ a < 1\)The number of correct digits roughly doubles each step. Newton's method, class 19.

Five rates side by side

Switch between log and linear scale. On the log scale the differences that matter for algorithms become visible.

A useful check. "Linear" in optimization does not mean the error falls along a straight line in ordinary units. It means the error is multiplied by roughly the same factor each step, which is a straight line on a log scale. And the smaller the factor, the faster. A linear rate with factor 0.5 beats one with factor 0.9 by a wide margin.

Summary

  • Descent methods move along a direction with \(\nabla f(x_k)^\top d_k < 0\) and make progress if the step is small enough.
  • Gradient descent uses \(d_k = -\nabla f(x_k)\), the steepest descent direction in the Euclidean norm. It produces a monotonically decreasing sequence of values for small enough steps.
  • It converges to a stationary point under assumptions, and to a global minimum if \(f\) is convex. Otherwise the starting point matters.
  • Speed is measured by the order and rate of convergence: sub-linear, linear, super-linear, quadratic.
How this shows up on the exam

True or false questions about the descent property are common. Gradient descent with a small enough step: a descent algorithm, true. Newton's method with step size 1 (class 19): not necessarily, it can be attracted to a maximum or overshoot. Stochastic gradient descent with a constant step (class 20): not necessarily, a noisy gradient estimate can increase \(f\).

Check yourself
Quick check
At \(x_k\) the gradient is \(\nabla f(x_k) = (2, -1)\). Which direction is not a descent direction?
Compute \(\nabla f(x_k)^\top d\): \(-5\), \(-2\) and \(2 - 1 = 1\). Only the last is positive, so moving along \((1, 1)\) increases \(f\) to first order.
Quick check
An algorithm's error behaves like \(e_k = 10^{-k}\). Its convergence is:
\(e_{k+1}/e_k = 0.1\) for every \(k\), so \(p = 1\) and \(\beta = 0.1\). One extra correct digit per iteration. Quadratic would look like \(10^{-2^k}\).
