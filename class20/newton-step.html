The Newton step

Gradient descent uses the slope and nothing else. Newton's method also uses the curvature. It replaces \(f\) by its best quadratic approximation and jumps straight to that quadratic's minimum.

Four design questions

Class 18 introduced the generic descent method for \(\min_{x \in \mathbb{R}^n} f(x)\): pick a direction \(d_k\) with \(\nabla f(x_k)^\top d_k < 0\), pick a step size \(\alpha_k > 0\), update \(x_{k+1} = x_k + \alpha_k d_k\), repeat. Every such method answers four questions:

  1. Initialization: where to start, \(x_0\).
  2. Descent: which direction \(d_k\).
  3. Step size: how far to go, \(\alpha_k\).
  4. Termination: when to stop, typically when \(\|\nabla f(x_k)\| \le \varepsilon\).

Gradient descent answered question 2 with \(d_k = -\nabla f(x_k)\). Newton's method gives a different answer, built from second derivatives.

The second-order view: minimize a quadratic model

Around the current point \(x\), approximate \(f\) by its second-order Taylor expansion:

\[ f(y) \approx \hat f(y) = f(x) + \nabla f(x)^\top (y - x) + \tfrac12 (y - x)^\top \nabla^2 f(x) (y - x). \]

Instead of minimizing \(f\), minimize the model \(\hat f\). Its first-order condition is a linear equation in \(y\):

\[ \nabla \hat f(y) = 0 \iff \nabla f(x) + \nabla^2 f(x)(y - x) = 0 \iff y = x - \big(\nabla^2 f(x)\big)^{-1} \nabla f(x). \]
Definition

Newton direction: \(d = -\big(\nabla^2 f(x)\big)^{-1} \nabla f(x)\).

Newton decrement: \(\lambda(x) = \big(\nabla f(x)^\top \nabla^2 f(x)^{-1} \nabla f(x)\big)^{1/2}\).

The decrement measures how much progress the model promises. The drop from \(f(x)\) to the model's minimum is exactly half its square:

\[ f(x) - \min_y \hat f(y) = f(x) - \hat f(x + d) = \tfrac12 \lambda(x)^2. \]
Why half the square?

Write \(g = \nabla f(x)\) and \(H = \nabla^2 f(x)\), so \(d = -H^{-1}g\). Plug into the model: \(\hat f(x + d) - f(x) = g^\top d + \tfrac12 d^\top H d = -g^\top H^{-1} g + \tfrac12 g^\top H^{-1} g = -\tfrac12 \lambda(x)^2\).

The first-order view: find a root of the gradient

Now forget about minimizing. A minimum is a stationary point, so we want to solve the equation \(\nabla f(y) = 0\). Linearize the gradient around \(x\):

\[ \nabla f(y) \approx g(y) = \nabla f(x) + \nabla^2 f(x)(y - x). \]

Setting \(g(y) = 0\) gives exactly the same point, \(y = x - \big(\nabla^2 f(x)\big)^{-1}\nabla f(x)\). This is the older reading. Newton and Raphson developed the method in the 1600s to solve systems of equations. Simpson extended it to optimization in the 1700s, by applying it to the equation \(\nabla f(y) = 0\).

Two views, one step

Second-order view: the minimizer of the quadratic model of \(f\). First-order view: the root of the linear model of \(\nabla f\). Both use the Hessian, so both approximate \(f\) better than gradient descent does.

Three things to notice:

  • Few steps. On \(6x - \log x\) from \(x_0 = 0.2\), four steps already give six correct digits of \(x^* = 1/6\).
  • Maxima attract too. On the non-convex quartic, start at \(x_0 = 0.4\), where \(f'' < 0\). The model is then an upside-down parabola, and Newton jumps to its top. The iterates converge to the local maximum. Newton solves \(\nabla f = 0\) and cannot tell a minimum from a maximum.
  • Some starts fail. On \(6x - \log x\), start at \(x_0 = 0.4\). The first step lands at \(-0.16\), outside the domain. Part b explains why.

The algorithm

Algorithm · Newton's method
  1. Choose a starting point \(x_0 \in \mathbb{R}^n\). Set \(k = 0\).
  2. Repeat until the stopping criterion holds:
    1. Compute the Newton direction \(d_k = -\big(\nabla^2 f(x_k)\big)^{-1}\nabla f(x_k)\).
    2. Update \(x_{k+1} = x_k + d_k\).
    3. Set \(k \leftarrow k + 1\).
  • "Pure" Newton always uses step size 1. Part c adds a step size \(\alpha_k \le 1\).
  • A second-order method. It uses the gradient and the Hessian. Each iteration makes more progress than gradient descent, but costs more: solving the \(n \times n\) linear system takes \(O(n^3)\) operations.
  • Stopping rule. Stop when the estimated improvement is small: \(\lambda(x_k)^2/2 \le \varepsilon\).

Logistic regression

The lecture's example fits a logistic regression by maximizing the log-likelihood:

\[ \max_\beta\ f(\beta) = \sum_{i=1}^n \Big\{ y_i x_i^\top \beta - \log\big(1 + e^{x_i^\top \beta}\big) \Big\}. \]

Its derivatives:

\[ \nabla f(\beta) = X^\top\big(y - p(X, \beta)\big), \quad p_i(X, \beta) = \frac{e^{x_i^\top\beta}}{1 + e^{x_i^\top\beta}}, \qquad \nabla^2 f(\beta) = -X^\top W X, \quad W = \mathrm{diag}\big(p_i(1 - p_i)\big). \]
  • \(\nabla^2 f(\beta) \preceq 0\), so maximizing \(f\) is a convex optimization problem.
  • The optimum is the stationary point: \(X^\top\big(y - p(X, \beta^*)\big) = 0\).

Newton's update for a maximization is the same formula, with the Hessian \(-X^\top W X\):

\[ \beta^{k+1} = \beta^k + (X^\top W X)^{-1} X^\top\big(y - p(X, \beta^k)\big) = (X^\top W X)^{-1} X^\top W z^k, \qquad z^k = X\beta^k + W^{-1}\big(y - p(X, \beta^k)\big). \]

Read the last form as a regression. It is the solution of a weighted least-squares problem:

\[ \beta^{k+1} = \arg\min_\beta\ (z^k - X\beta)^\top W (z^k - X\beta). \]

So each Newton step refits a weighted linear regression to an adjusted response \(z^k\), with weights \(W\) that are recomputed from the current fit. This is why the method is called iteratively re-weighted least squares (IRLS). Data points with \(p_i\) near 0.5 get the most weight, since the model is least certain about them.

Summary

  • Newton direction \(d = -\big(\nabla^2 f(x)\big)^{-1}\nabla f(x)\): minimize the quadratic model of \(f\), or equivalently find the root of the linear model of \(\nabla f\).
  • Newton decrement \(\lambda(x)^2 = \nabla f(x)^\top \nabla^2 f(x)^{-1} \nabla f(x)\). The model predicts a decrease of \(\lambda(x)^2/2\), which is also the stopping rule.
  • Pure Newton uses step size 1. Each iteration costs \(O(n^3)\) and makes much more progress than a gradient step.
  • For logistic regression, Newton's method is iteratively re-weighted least squares.
How this shows up on the exam

The practice exam asks for one-dimensional Newton iterates by hand. In one dimension the update is simply \(x_{k+1} = x_k - f'(x_k)/f''(x_k)\). For \(f(x) = 6x - \log x\) this is \(x_{k+1} = x_k - x_k^2(6 - 1/x_k) = 2x_k - 6x_k^2\). Part b finishes the problem.

Check yourself
Quick check
\(f(x) = \tfrac12 x^\top Q x - c^\top x\) with \(Q \succ 0\). From any \(x_0\), where does one pure Newton step land?
For a quadratic, the second-order model is \(f\) itself. Newton minimizes the model, so it lands on the minimizer: \(x_1 = x_0 - Q^{-1}(Qx_0 - c) = Q^{-1}c\).
Quick check
At \(x_k\), \(\nabla f(x_k) = (2, 0)\) and \(\nabla^2 f(x_k) = \mathrm{diag}(4, 1)\). What is \(\lambda(x_k)^2/2\), the improvement the model predicts?
\(\lambda^2 = \nabla f^\top (\nabla^2 f)^{-1} \nabla f = 2 \cdot \tfrac14 \cdot 2 = 1\), so \(\lambda^2/2 = 0.5\). The Newton direction is \(d = (-0.5, 0)\).
