Reformulation via duality

When the uncertainty set is a polyhedron, the adversary solves a linear program. Strong duality turns its maximization into a minimization, and a minimization inside a "less than" constraint is easy to remove.

The key trick

The robust constraint \(\max_{a_i \in \mathcal{U}_i} a_i^\top x \le b_i\) is awkward because of the max. Suppose we could rewrite the inner problem as a minimization over some new variables \(p_i\) in a set \(\mathcal{V}_i\):

\[ \max_{a_i \in \mathcal{U}_i} a_i^\top x = \min_{p_i \in \mathcal{V}_i} g(p_i). \]

Then "the minimum is at most \(b_i\)" just means "some \(p_i\) achieves at most \(b_i\)":

\[ \min_{p_i \in \mathcal{V}_i} g(p_i) \le b_i \quad\iff\quad \exists\, p_i \in \mathcal{V}_i : g(p_i) \le b_i. \]

So we can add \(p_i\) as ordinary decision variables next to \(x\), and the inner optimization disappears. Strong duality of linear programming provides exactly this max-to-min switch.

Why the direction matters

A max on the left of \(\le\) is hard: it must hold for the worst case. A min on the left of \(\le\) is easy: you only need one witness. Duality turns the first into the second.

Polyhedral uncertainty sets

Definition (polyhedral uncertainty set)

Let \(D_i \in \mathbb{R}^{\ell_i \times n}\) and \(d_i \in \mathbb{R}^{\ell_i}\). Then

\[ \mathcal{U}_i = \big\{ a_i = \bar a_i + u_i : D_i u_i \le d_i \big\}. \]

Any set described by finitely many linear inequalities fits: the box, the CLT set from class 13, the nurse scheduling set, and combinations of them.

The derivation

Fix \(x\). The adversary solves a linear program in \(u_i\):

\[ \max_{a_i \in \mathcal{U}_i} a_i^\top x = \bar a_i^\top x + \max_{u_i} \{ x^\top u_i : D_i u_i \le d_i \}. \]

Take the LP dual of \(\max\{x^\top u_i : D_i u_i \le d_i\}\). One dual variable per row of \(D_i\), nonnegative because the primal constraints are \(\le\) in a max problem, and one dual equality per free primal variable \(u_{ij}\):

\[ \min_{p_i}\ \{ p_i^\top d_i : p_i^\top D_i = x^\top,\ p_i \ge 0 \}. \]

If the set is nonempty and bounded, strong duality says both optimal values are equal.

Substitute and use the key trick:

\[ \max_{a_i \in \mathcal{U}_i} a_i^\top x \le b_i \quad\iff\quad \exists\, p_i \ge 0 :\ p_i^\top D_i = x^\top,\ \ \bar a_i^\top x + p_i^\top d_i \le b_i. \]
Proposition (polyhedral uncertainty)

The robust problem is equivalent to the linear program

\[ \begin{aligned} \max_{x,\, p}\ & c^\top x \\ \text{s.t. } & \bar a_i^\top x + p_i^\top d_i \le b_i, && i = 1, \dots, m \\ & p_i^\top D_i = x^\top, && i = 1, \dots, m \\ & p_i \ge 0,\ x \ge 0. \end{aligned} \]
  • The robust counterpart is a linear program.
  • Its size grows with the description of the sets: \(n + \sum_i \ell_i\) variables, \(m + nm\) ordinary constraints and \(n + \sum_i \ell_i\) sign constraints. It is still tractable in practice.

Worked example: a budget of deviations

One constraint \(\sum_j a_j x_j \le b\) with \(x \ge 0\). Each coefficient can rise above its nominal value by up to \(\hat a_j\), but at most \(\Gamma\) of them can be fully off at once:

\[ \mathcal{U} = \Big\{ a : a_j = \bar a_j + \hat a_j z_j,\ \ 0 \le z_j \le 1,\ \ \sum_j z_j \le \Gamma \Big\}. \]

Step 1, inner problem. For fixed \(x \ge 0\), the adversary solves

\[ \bar a^\top x + \max_z \Big\{ \sum_j \hat a_j x_j z_j \ :\ \sum_j z_j \le \Gamma,\ \ z_j \le 1,\ \ z \ge 0 \Big\}. \]

Intuition: the adversary spends its budget \(\Gamma\) on the coefficients with the largest \(\hat a_j x_j\).

Step 2, dual. Give the budget constraint the multiplier \(\lambda \ge 0\) and each \(z_j \le 1\) the multiplier \(\mu_j \ge 0\):

\[ \min_{\lambda, \mu}\ \Gamma\lambda + \sum_j \mu_j \quad \text{s.t.}\quad \lambda + \mu_j \ge \hat a_j x_j\ \ \forall j,\qquad \lambda \ge 0,\ \mu \ge 0. \]

Step 3, robust counterpart. Replace the max by the dual and drop the min:

\[ \bar a^\top x + \Gamma\lambda + \sum_j \mu_j \le b, \qquad \lambda + \mu_j \ge \hat a_j x_j\ \ \forall j, \qquad \lambda, \mu \ge 0. \]

All linear in \((x, \lambda, \mu)\). This is the budget-of-uncertainty model from Bertsimas and Sim.

Check with numbers

Let \(\hat a_j x_j = (5, 3, 2)\) and \(\Gamma = 1.5\). The adversary puts \(z_1 = 1\) and \(z_2 = 0.5\): extra \(5 + 1.5 = 6.5\).

Dual: take \(\lambda = 3\) (the second largest term), \(\mu = (2, 0, 0)\). Then \(\Gamma\lambda + \sum \mu_j = 4.5 + 2 = 6.5\), and every constraint \(\lambda + \mu_j \ge \hat a_j x_j\) holds. Same value, as strong duality promises.

How this shows up on the exam

Last year's midterm asked exactly this kind of derivation for a supply-side constraint: yields \(q_{ij}\) bounded below by \(\hat q_{ij}\), with a lower bound on their total. The structure is the same. Write the inner problem (a min, because the constraint is \(\ge\)), take its dual (a max), and replace. Be careful with the signs of the dual variables when the inner problem is a minimization.

The complete table

For the robust problem \(\max c^\top x\) s.t. \(\max_{a_i \in \mathcal{U}_i} a_i^\top x \le b_i\), \(x \ge 0\):

Set\(\mathcal{U}_i^0\)Robust counterpartType
Box\(\|u_i\|_\infty \le \rho\)\(\bar a_i^\top x + \rho\|\Delta_i x\|_1 \le b_i\)Linear
Ellipsoidal\(\|u_i\|_2 \le \rho\)\(\bar a_i^\top x + \rho\|\Delta_i x\|_2 \le b_i\)Conic
Budget\(\|u_i\|_1 \le \Gamma\)\(\bar a_i^\top x + \Gamma\|\Delta_i x\|_\infty \le b_i\)Linear
Budget-box\(\|u_i\|_\infty \le \rho,\ \|u_i\|_1 \le \Gamma\)\(\bar a_i^\top x + \rho\|y\|_1 + \Gamma\|\Delta_i x - y\|_\infty \le b_i\)Linear

In the budget-box row, \(y\) is an extra free vector of variables: the buffer is split between a part paid at the box rate and a part paid at the budget rate.

Summary

  • Duality turns the adversary's max into a min, and a min on the left of \(\le\) can be dropped by adding the dual variables to the problem.
  • Polyhedral sets give linear robust counterparts, larger than the nominal problem but tractable.
  • Recipe: inner problem, dual, substitute, keep the dual constraints.
Check yourself
Quick check
Why can the "min" be dropped in \(\min_{p \in \mathcal{V}} g(p) \le b\)?
The solver will choose \(p\) to make the constraint as easy as possible, which reproduces the minimum. This only works for a min on the small side of the inequality.
