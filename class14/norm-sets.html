Norm sets and dual norms

The robust constraint hides a maximization: the adversary's best response. For sets shaped like norm balls, that maximization has a closed-form answer, and the robust constraint becomes the nominal one plus a safety buffer.

The problem with infinitely many constraints

Class 13 wrote the robust problem as

\[ \max\ c^\top x \quad \text{s.t.}\quad a_i^\top x \le b_i \quad \forall a_i \in \mathcal{U}_i,\ i = 1, \dots, m, \qquad x \ge 0. \]

That is one constraint for every \(a_i\) in the set: infinitely many. An equivalent way to say "for all \(a_i\)" is "for the worst \(a_i\)":

\[ \max_{a_i \in \mathcal{U}_i} a_i^\top x \le b_i, \qquad i = 1, \dots, m. \]

Now there are finitely many constraints, but each contains an optimization problem. A solver cannot take that directly. Class 14 gives two ways out: reformulate the inner problem (parts a and b), or generate constraints one at a time (part c).

The direct method

Suppose we can solve the inner problem by hand and get a formula \(g_i(x) = \max_{a_i \in \mathcal{U}_i} a_i^\top x\). Then the robust problem is simply

\[ \max\ c^\top x \quad \text{s.t.}\quad g_i(x) \le b_i,\ i = 1, \dots, m, \qquad x \ge 0. \]

For well-structured sets based on norms, \(g_i\) has a clean closed form. That is what makes them so popular.

Norm uncertainty sets

Both sets from class 13 describe small deviations around a nominal value \(\bar a_i\): either each component separately (the box) or in total (the CLT set). The general template is:

Definition (norm uncertainty set)

Let \(\Delta_i \in \mathbb{R}^{k_i \times n}\) and \(\rho \ge 0\). Then

\[ \mathcal{U}_i = \big\{ a_i \in \mathbb{R}^n : a_i = \bar a_i + \Delta_i^\top u_i,\ \|u_i\| \le \rho \big\}. \]
  • \(u_i\) is the perturbation. Its norm, at most \(\rho\), controls how much uncertainty there is.
  • \(\Delta_i\) scales the perturbation, so some coefficients can be more uncertain than others (for example \(\Delta_i = \mathrm{diag}(\sigma_1, \dots, \sigma_n)\)).
  • The choice of norm sets the shape.
Norm on \(u\)Shape of the setName
\(\|u\|_\infty = \max_j |u_j|\)BoxBox uncertainty
\(\|u\|_2 = \sqrt{\sum_j u_j^2}\)EllipsoidEllipsoidal uncertainty
\(\|u\|_1 = \sum_j |u_j|\)Diamond (cross-polytope)Budget uncertainty

The ellipsoidal set, step by step

Take \(\|u_i\|_2 \le \rho\). Split the inner problem into a nominal part and a perturbation part:

\[ Z_i = \max_{a_i \in \mathcal{U}_i} a_i^\top x = \bar a_i^\top x + \max_{\|u_i\|_2 \le \rho} u_i^\top (\Delta_i x). \]
\[ \max_{\|u_i\|_2 \le \rho} u_i^\top (\Delta_i x) = \rho\,\|\Delta_i x\|_2. \]

In words: the adversary points its perturbation in the same direction as \(\Delta_i x\), with full length \(\rho\).

Try \(u_i^* = \rho\, \dfrac{\Delta_i x}{\|\Delta_i x\|_2}\).

It is feasible: \(\|u_i^*\|_2 = \rho\).

Its value is \((u_i^*)^\top (\Delta_i x) = \rho\, \dfrac{\|\Delta_i x\|_2^2}{\|\Delta_i x\|_2} = \rho\, \|\Delta_i x\|_2\).

By the Cauchy-Schwarz inequality, every feasible \(u_i\) satisfies

\[ u_i^\top (\Delta_i x) \le \|u_i\|_2\, \|\Delta_i x\|_2 \le \rho\, \|\Delta_i x\|_2. \]

So no feasible \(u_i\) does better than \(u_i^*\), which proves the claim.

Proposition (ellipsoidal uncertainty)

The robust counterpart is

\[ \max\ c^\top x \quad \text{s.t.}\quad \bar a_i^\top x + \rho\,\|\Delta_i x\|_2 \le b_i,\ i = 1, \dots, m, \qquad x \ge 0. \]
  • Interpretation: the term \(\rho\|\Delta_i x\|_2\) is a safety buffer. The more uncertainty, the bigger the buffer.
  • Size: the same as the nominal problem: \(n\) variables and \(m\) constraints.
  • Type: a second-order cone program, a special class of convex optimization that solvers handle efficiently. The robust counterpart is nearly as tractable as the nominal LP.

The dual norm and the general rule

Definition (dual norm)

For a norm \(\|\cdot\|\), its dual norm is

\[ \|s\|_* = \max_{\|x\| \le 1} s^\top x. \]

It measures how large the inner product with \(s\) can get when \(x\) ranges over the unit ball.

With this definition, the argument above works for any norm. Substitute \(u_i = \rho v_i\):

\[ \max_{a_i \in \mathcal{U}_i} a_i^\top x = \bar a_i^\top x + \max_{\|u_i\| \le \rho} u_i^\top (\Delta_i x) = \bar a_i^\top x + \rho \max_{\|v_i\| \le 1} v_i^\top (\Delta_i x) = \bar a_i^\top x + \rho\, \|\Delta_i x\|_*. \]
Proposition (norm uncertainty)
\[ a_i^\top x \le b_i\ \ \forall a_i \in \mathcal{U}_i \quad\iff\quad \bar a_i^\top x + \rho\, \|\Delta_i x\|_* \le b_i. \]

The dual of \(\ell_p\) is \(\ell_q\) with \(\tfrac1p + \tfrac1q = 1\). The three cases to know:

Set (norm on \(u\))Dual normRobust counterpartTractability
Box, \(\|u_i\|_\infty \le \rho\)\(\ell_1\)\(\bar a_i^\top x + \rho\|\Delta_i x\|_1 \le b_i\)Linear
Ellipsoidal, \(\|u_i\|_2 \le \rho\)\(\ell_2\)\(\bar a_i^\top x + \rho\|\Delta_i x\|_2 \le b_i\)Conic
Budget, \(\|u_i\|_1 \le \Gamma\)\(\ell_\infty\)\(\bar a_i^\top x + \Gamma\|\Delta_i x\|_\infty \le b_i\)Linear
Why the \(\ell_1\) and \(\ell_\infty\) versions are linear

\(\|\Delta_i x\|_1 = \sum_j |(\Delta_i x)_j|\). Add variables \(y_j \ge (\Delta_i x)_j\) and \(y_j \ge -(\Delta_i x)_j\), and replace the norm by \(\sum_j y_j\). For \(\|\Delta_i x\|_\infty\), add one variable \(t \ge \pm(\Delta_i x)_j\) for all \(j\). Both turn the robust constraint into ordinary linear constraints.

Seeing it

Interactive

The adversary's best response

The shaded shape is the set of allowed perturbations \(u\) (with \(\rho = 1\)). For a given vector \(\Delta x\), the adversary picks the \(u\) in the set that maximizes \(u^\top (\Delta x)\). That maximum is the dual norm.

Notice how the box always picks a corner (every component at its extreme, which gives the \(\ell_1\) norm), the ball points straight along \(\Delta x\), and the diamond puts its whole budget on the single largest component (the \(\ell_\infty\) norm).

Summary

  • The robust constraint is \(\max_{a_i \in \mathcal{U}_i} a_i^\top x \le b_i\). Solve the inner maximization and substitute.
  • For norm sets the answer is a safety buffer: \(\bar a_i^\top x + \rho\|\Delta_i x\|_* \le b_i\).
  • Box gives \(\ell_1\) (linear), ellipsoid gives \(\ell_2\) (second-order cone), budget gives \(\ell_\infty\) (linear).
How this shows up on the exam

"Derive the robust counterpart" questions usually follow the three steps on this page: split off the nominal part, solve the adversary's problem with a dual norm (or with LP duality, part b), and substitute back. Always state the final constraint explicitly and say whether the result is linear or conic.

Check yourself
Quick check
\(\bar a = (1, 2)\), \(\Delta = I\), box set with \(\rho = 0.5\), and \(x = (2, -1)\). What is \(\max_{a \in \mathcal{U}} a^\top x\)?
\(\bar a^\top x = 2 - 2 = 0\), and the buffer is \(\rho\|x\|_1 = 0.5 \cdot 3 = 1.5\). The \(\sqrt{5}\) answer would be the ellipsoidal set.
