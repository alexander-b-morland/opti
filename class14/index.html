Class 14 · Optimization under uncertainty

Robust optimization algorithms

A robust constraint must hold for infinitely many data values. Two tools make that solvable: rewrite the worst case in closed form, or generate the worst cases one at a time.

Overview

The big picture

Class 13 wrote down robust problems. Class 14 solves them. Every method rests on one move: replace "for all \(a_i\) in the set" by "for the worst \(a_i\) in the set".

\[ a_i^\top x \le b_i\ \ \forall a_i \in \mathcal{U}_i \quad\iff\quad \max_{a_i \in \mathcal{U}_i} a_i^\top x \le b_i \]

A building inspector must certify that a bridge survives every possible load in a range. Checking each load one by one is impossible. Either the engineer derives a formula for the worst load and checks only that (reformulation), or the inspector keeps proposing the nastiest load for the current design until the design survives them all (cutting planes).

Solve the adversary's inner problem analytically. For norm sets the answer is a dual norm, \(\bar a_i^\top x + \rho\|\Delta_i x\|_* \le b_i\). For polyhedral sets, LP duality turns the inner max into a min, whose variables join the problem. One solve, no iterations.

Keep a finite list of scenarios. Solve the master problem, ask the adversary for the worst scenario for that solution, add it, repeat. Works for any set where the adversary's problem can be solved.

The story of the class in three steps

14a · Norm setsBox, ellipsoid, budget. The worst case is a dual norm.
14b · DualityPolyhedral sets. The worst case is an LP, and duality removes it.
14c · Cutting planesAsk the adversary, add the cut, repeat.
Takeaways from the lecture
  1. Robust optimization can be solved by reformulation (robust counterpart via strong duality) or by cutting planes (master problem plus subproblem).
  2. Cutting planes also works without strong duality.
  3. Robust problems are tractable in practice for a wide range of problems and uncertainty sets.
  4. Robust solutions protect against real-world data perturbations and changes in the operating environment.

Exam practice

Test yourself

Multiple choice in the style of the midterm. Say your one-line justification before you click.

Question 1 · Cutting planes
Cutting planes for \(\max c^\top x\) s.t. \(a_i^\top x \le b_i\ \forall a_i \in \mathcal{U}_i\). At each iteration we obtain an upper bound on the robust optimal value. True or false?
The master problem keeps only finitely many of the constraints, so it is a relaxation of a maximization problem. Its optimal value is at least the robust optimum.
Question 2 · Dual norm
The set is \(\{\bar a + u : \|u\|_1 \le \Gamma\}\). The robust counterpart of \(a^\top x \le b\) is:
The dual of \(\ell_1\) is \(\ell_\infty\). The adversary spends its whole budget on the single coordinate where \(|x_j|\) is largest.
Question 3 · Tractability
Which robust counterpart is not a linear program?
The ellipsoidal buffer \(\rho\|\Delta x\|_2\) gives a second-order cone constraint. It is still convex and efficiently solvable, but not linear.
Question 4 · Computation
\(\bar a = (3, 1)\), \(\Delta = I\), ellipsoidal set with \(\rho = 2\), \(x = (3, 4)\). What is \(\max_{a \in \mathcal{U}} a^\top x\)?
\(\bar a^\top x = 9 + 4 = 13\), and \(\rho\|x\|_2 = 2 \cdot 5 = 10\). Total 23. A box set with the same \(\rho\) would give \(13 + 2 \cdot 7 = 27\).
Question 5 · Duality
In the polyhedral reformulation, why are the new dual variables \(p_i\) nonnegative?
In the dual of a max problem, a \(\le\) constraint gets a nonnegative multiplier. The free primal variables \(u_i\) produce the equality \(p_i^\top D_i = x^\top\).
Question 6 · Sets compared
Same \(\rho\), same \(\Delta\). Rank the robust optimal values of a maximization problem under the box (\(Z_\infty\)), ellipsoidal (\(Z_2\)) and budget (\(Z_1\)) sets.
For the same radius, the \(\ell_1\) ball sits inside the \(\ell_2\) ball, which sits inside the \(\ell_\infty\) ball. A larger set means a smaller robust feasible region and a lower maximum.
