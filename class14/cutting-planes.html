Cutting planes

Instead of reformulating, ask the adversary directly. Solve with the constraints you have, find the worst case for that solution, add it, and repeat until the adversary has nothing left to say.

The idea

Out of the infinitely many robust constraints, only a few actually matter at the optimum. Cutting planes finds them on demand. All it needs is the ability to solve the adversary's problem \(\max_{a_i \in \mathcal{U}_i} a_i^\top x\) for a given \(x\). No duality, no closed form.

Master problemSolve with a finite list of scenarios \(\bar{\mathcal{U}}_i \subseteq \mathcal{U}_i\).
SubproblemFor the master's \(x\), find the worst \(a_i^*\) in the full set \(\mathcal{U}_i\).
UpdateIf \(a_i^{*\top} x > b_i\), add \(a_i^*\) to the list. Otherwise stop.

The algorithm

Algorithm · cutting planes for robust optimization

Inputs: \(b\), \(c\), sets \(\mathcal{U}_1, \dots, \mathcal{U}_m\), tolerance \(\varepsilon > 0\).

  1. Initialize the master problem as the nominal problem: \(\bar{\mathcal{U}}_i = \{\bar a_i\}\) for all \(i\).
  2. Solve the master problem \(\max c^\top x\) s.t. \(a_i^\top x \le b_i\ \forall a_i \in \bar{\mathcal{U}}_i\), \(x \ge 0\).
    1. If it is infeasible, stop: the robust problem is infeasible too.
    2. If it is unbounded, take some \(x\) with a very large objective, larger than a big constant \(M\).
    3. Otherwise, take its optimal solution \(x\).
  3. For each row \(i\), solve the subproblem \(a_i^* = \arg\max_{a_i \in \mathcal{U}_i} a_i^\top x\). If \(a_i^{*\top} x > b_i + \varepsilon\), add \(a_i^*\) to \(\bar{\mathcal{U}}_i\).
  4. If no constraint was added, stop: \(x\) is robust optimal (within \(\varepsilon\)). Otherwise go to step 2.

Each new master problem is the old one plus a few constraints, so it can be re-solved quickly from the previous solution with the dual simplex method.

Cutting planes on a small robust LP

Maximize \(3x_1 + 4x_2\) with an ellipsoidal set on the coefficients of \(a_1x_1 + a_2x_2 \le 12\). The shaded region is the true robust feasible set, whose boundary is curved. Each cut is a straight line that touches it from outside.

The cuts approximate the curved robust boundary by straight lines, but only near the optimum, where it matters. A handful of iterations reaches the robust solution.

Why each master gives a bound

The master problem only enforces the constraints for a subset \(\bar{\mathcal{U}}_i \subseteq \mathcal{U}_i\). It is a relaxation of the robust problem: fewer constraints, larger feasible region. For a maximization problem:

  • Every master optimal value is an upper bound on the robust optimal value.
  • Adding cuts can only lower the master value, so the bounds get tighter at every iteration.
  • Every intermediate master solution, except the last, is infeasible for the robust problem. That is why it got cut off.
How this shows up on the exam

A practice question from last year: "At each iteration of the cutting planes algorithm for a robust maximization problem, we obtain an upper bound on the optimal value. True or false?" True, for exactly the reason above. For a minimization problem, the master gives a lower bound.

Back to nurse scheduling

The nurse scheduling model from class 13 protects the nurse-to-patient insufficiency against every demand profile \(h\) in a polyhedral set \(\mathcal{U}\). Cutting planes solves it like this:

Algorithm · cutting planes for nurse scheduling
  1. Start with the historical demand only: \(\bar{\mathcal{U}}^0 = \{h^{\text{hist}}\}\). Set \(\ell = 1\) and a tolerance \(\varepsilon\).
  2. Solve the master problem with demand scenarios \(\bar{\mathcal{U}}^{\ell-1}\), and get a schedule \(z^\ell\).
  3. Find the worst demand for that schedule: \(h^\ell \in \arg\max_{h \in \mathcal{U}} \text{npr}(h, z^\ell)\).
  4. Add it: \(\bar{\mathcal{U}}^\ell = \{h^{\text{hist}}, h^1, \dots, h^\ell\}\), and set \(\ell \leftarrow \ell + 1\).
  5. Stop when the relative change in insufficiency is below \(\varepsilon\). Otherwise go to step 2.

Each subproblem is a linear program over demand profiles. Each new scenario is a realistic "bad week" for the current schedule.

Reformulation or cutting planes?

Reformulation (robust counterpart)Cutting planes
HowRewrite the inner max in closed form or with strong duality. Solve one problem.Alternate between a master problem and adversarial subproblems.
NeedsA tractable dual or closed form for the setOnly a way to solve \(\max_{a_i \in \mathcal{U}_i} a_i^\top x\)
ScopeA wide range of standard setsAny set, even without strong duality
Speed in benchmarksTends to win with ellipsoidal setsTends to win with polyhedral sets

The benchmark comparison is from Bertsimas, Dunning and Lubin (2016), cited in the lecture: both methods are competitive in practice.

Summary

  • Cutting planes alternates a master problem (finite scenarios) and subproblems (worst case for the current solution).
  • It needs only an oracle for the adversary's problem.
  • For a maximization problem each master value is an upper bound, and the bounds tighten monotonically.
  • Robust optimization is tractable in practice with either method, for many problems and many sets.
